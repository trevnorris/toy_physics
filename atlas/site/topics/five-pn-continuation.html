Physical Picture

The 5PN material is a continuation layer, not a frozen published endpoint. It packages a reduced full-bundle surface and identifies which branch-placement and even-gate conditions remain.

Physically, this page sits after the quadrupole and response-packet pages. It asks whether the same finite-mouth branch can supply the higher grouped response moments needed beyond the already published PN ladder.

The full-bundle surface is a target for branch-exported data. It is not a new physical throat object and it is not evidence that the actual moving-throat branch has already landed on the surface.

The weak-axisymmetric side of the page is the route into orbit-lock and g-2 style quotient language. That route is useful only if the branch exports the tangent target-blind.

Readers should treat this as a precise map of future branch computation rather than as a completed 5PN paper.

Mathematical Core

The isotropic full-bundle surface combines the one-pole condition with the quadrupole-normalization condition already visible in Packet A.

The monomial quotient separates true branch motion from similarity-orbit motion. It gives a coherent coordinate system for weak-axisymmetric defects, but it does not close K1 or H_even by itself.

The weak-axisymmetric grouped signature records the first-order angular splitting law, while the prefactor slope Xi1=P1/P0 records the outgoing-prefactor response.

The remaining branch tasks are concrete. The exporter must land on the full-bundle surface, derive independent N2 and N4 moment-shape controls, and supply the weak-axisymmetric orbit-lock tangent where Packet B is used.

Public pages should keep the similarity/orbit theorem separate from full 5PN closure because the theorem controls a normalization-defect direction, not the separate conservative even gates.

Status

This page should remain paper pending until the 5PN derivation is promoted from notes to a formal paper.

The displayed equations are valid reduced target surfaces or branch coordinates, but the actual target-blind moving-throat branch realization is still open.

Future work should add a later-development result once the branch exporter supplies Packet A and Packet B data, rather than editing this page into an unconditional closure claim.
