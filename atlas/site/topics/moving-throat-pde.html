Moving-throat PDE program

The moving-throat program studies wall/support dynamics, branch selection, and response export, but some parts are currently notes-backed rather than formal paper-backed.

paper pending 10 selected graph nodes · 8 paper-pending source entries

Physical Picture

This is the active bridge from a static or reduced throat picture to an executable physical branch. It asks which wall variables, material laws, and boundary packets the same branch must export.

The public page should be candid: much of this is organized and audited, but not all of it has a frozen formal paper yet.

Mathematical Core

The wall PDE is exact only relative to the action that contains the wall term. The current parent action and the promoted parent action therefore need separate labels.

The branch exporter is the mathematical object that should eventually connect PDE solutions to PN and anomaly response packets.
