Moving-throat PDE program

The moving-throat program studies wall/support dynamics, branch selection, and response export, but some parts are currently notes-backed rather than formal paper-backed.

paper pending 21 selected graph nodes · 13 paper-pending source entries

Physical Picture

This is the active bridge from a static or reduced throat picture to an executable physical branch. It asks which wall variables, material laws, mixed-sector plumbing, and boundary packets the same branch must export.

A moving throat is not just a geometric label. It needs support variables, constitutive coefficients, boundary data, material closure, and a branch solver that can be run before any comparison to PN or anomaly targets.

The present status is split. The effective wall modal equation is valid when the wall action is included, but the confinement-only parent action does not by itself prove autonomous moving-wall dynamics.

The branch exporter is the central missing object. It must solve and freeze a physical branch first, then export response packets for PN or anomaly comparison without reading the target.

This is where quadrupole normalization becomes an executable problem rather than a target equation. The same branch has to supply the radial, axial, outgoing, and material data used downstream.

Mathematical Core

The quadratic wall action S_eta^(2) generates the effective scalar and P2 wall equations. It is a controlled linear wall closure, not yet a strict parent-level nonlinear wall theory.

Strict parent-level status requires the promoted S_Sigma action. Its quadratic limit should reproduce the effective wall closure, but the nonlinear completion remains an open gate.

The electromagnetic block now follows the projection-first ledger ordering: Stages 004--020 derive the projected Maxwell packet, and Stage 021 keeps the reduced one-port normal form only as the downstream adapter.

The selected-mode stages convert radial and axial branch data into a spectral reachability packet for the remaining normalization targets.

The branch exporter should output quantities such as K, M, B_n, Z_n, N_n, P0, N2, and N4 as frozen data from the solved branch, not as adjustable fit knobs.

Material closure and mixed recirculation have to close on the same branch. Density, sound speed, effective light cone, intake/output flux, A_w, F_muw, and current-source plumbing cannot be solved as detached post-processing.

Status

This page is intentionally notes-backed and paper-pending. It should point readers to the current audited program while making clear that the formal moving-throat paper is still future work.

Do not read the wall PDE as already parent-exact. It is exact relative to an action containing the wall term, and strict parent status depends on the promoted wall/support sector.

Keep wall coefficients as branch or constitutive data. They are not post-hoc parameters to rescue a target comparison.

Once the PDE paper or maintained ledger components are published, the source links can be backfilled without rewriting the earlier status boundaries.
