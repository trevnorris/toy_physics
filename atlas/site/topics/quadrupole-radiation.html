Quadrupole radiation and the 2.5PN normalization gate

The 2.5PN sector narrows the dissipative problem to an outgoing quadrupole normalization target, but the actual branch data must still supply the normalization.

Physical Picture

This page is the gate between the published PN ladder and the still-active moving-throat branch program. It explains why the 2.5PN result is a strong narrowing theorem but not yet an unconditional solved-branch theorem.

The scalar and dipole danger channels are demoted on the natural branch, leaving the orbital or worldtube STF quadrupole as the surviving universal dissipative route.

The current PDE ledger gets to this outgoing port through the projection-first electromagnetic packet in Stages 004--020, then uses the retained Stage 021 reduced one-port adapter before the grouped normalization bridge.

The outgoing quadrupole port is the physical place where the branch must speak. It must export the passive outgoing response with the correct normalization before the 2.5PN and inherited 4PN tail statements can be upgraded.

The angular source-map result is real progress: the canonical STF angular basis maps into the grouped P2 ports cleanly. But angular closure is only the angular part of the problem.

The remaining issue is radial, axial, and port-amplitude data. The same branch must provide the source scale and outgoing prefactor as branch data, not as a coefficient fitted after comparing with the PN target.

Mathematical Core

The compact outgoing l=2 fingerprint fixes the universal low-frequency structure of the outgoing quadrupole response. Its imaginary omega^5 term is the bridge into the dissipative 2.5PN coefficient.

In the reordered ledger, that fingerprint is anchored after projected EM by the Stage 021 one-port adapter, while Stage 022 records the grouped P2 normalization bridge.

The central target is an invariant product involving the source scale and outgoing response coefficient. The graph records it as EQ_P0_TARGET and protects it with open-gate status.

In reduced grouped-P2 language, the leading odd coefficient depends on the isotropic static outgoing prefactor. The branch must therefore deliver P0 or the equivalent N0/D0 readout through the response-packet machinery.

The STF source-map theorem and O(3) angular isotropy organize the basis and remove angular ambiguity. They do not compute the radial selected branch, the axial normalization, or the outgoing port amplitude.

Exact angular source-map facts should not be upgraded into radial or axial normalization closure. That is why the angular-not-radial firewall belongs on the public page.

Status

Published papers describe the conditional narrowing and the inherited 4PN tail dependence. The PDE ledger supplies useful stage evidence, but some supporting branch-export details remain paper pending.

Future work should add a closure paper or executable branch computation rather than mutate this status. When the gate closes, the graph should show target-blind branch data that lands on the normalization before target comparison.

Safe summary: the quadrupole route is isolated; the angular basis is controlled; the outgoing normalization is still an open branch-output gate.
