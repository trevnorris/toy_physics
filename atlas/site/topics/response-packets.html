Branch response packets and target-blind export

The model needs branch data exported before comparison to PN or anomaly targets; response packets must be target-blind and downstream of the physical branch.

paper pending 10 selected graph nodes · 6 paper-pending source entries

Physical Picture

A response packet is the branch's exported data, not a physical object in its own right. That distinction keeps the comparison to target coefficients honest.

Packet A carries conservative/outgoing normalization data; Packet B carries orbit-lock or weak-axisymmetric data where relevant.

Mathematical Core

The weak-form branch extractor is the planned interface between solved profiles and invariant packet data. It should output quantities such as K, M, B_n, Z_n, N_n, and grouped projectors without reading the target first.

This page should be treated as the public checklist for future executable branch solvers.
