Status firewalls: what the site must not overclaim

Status firewalls are public guardrails that block invalid upgrades such as projection equals reduction, local 4PN equals full tail closure, or g-2 already closed.

Physical Picture

Firewalls are not bureaucracy. They are how the public site stays honest while summarizing a large derivation program.

A reader should be able to tell immediately which results are exact, which are conditional, and which are open branch targets.

Mathematical Core

The graph represents invalid inferences as explicit nodes and negative queries. Public topic pages should surface the relevant firewall wherever a tempting shortcut exists.

This also gives future papers a checklist: closing a gate means changing graph status with source support, not editing prose alone.
