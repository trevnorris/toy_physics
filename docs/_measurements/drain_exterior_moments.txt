Finite-mouth exterior comparison. Repository base d544ef73.
The symbolic and numerical calculations below use a prescribed, steady inward normal velocity on an enclosing sphere.
A first Wolfram quadrature in unrotated angular coordinates reported NIntegrate::eincr and an error estimate above the intended tolerance. It was stopped. The revised calculation integrates the azimuth analytically. Only the completed run below supplies the numerical results.
