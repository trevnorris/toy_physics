Finite-grid rim push on the radius-one resting drain, two-engine compatibility check.
Working record, independent code paths with shared model assumptions. Repository base fd667ea9291b4430a96afe3fd932926232f5507d.
The numerical control uses the same unperturbed carrier face and inward current. The Python process copies the three raw arrays (real face, imaginary face, normal current) to little-endian binary for Mathematica. Mathematica rebuilds the periodic mask and readout independently, using summation by parts for the mixed stress. The offsets are -1, 0 and +1 grid cell, at frozen fields; none is a free release.
For a smooth release the incremental exterior load starts at order t squared. Both the time series and the high-frequency calculation leave a brane-only force-balance residual equal to the signed applied step at onset. The wall endpoint variation changes the unresolved profile while keeping endpoint displacement and slope fixed. No bare mass is assigned, and no force-driven physical trajectory was generated.
Largest absolute discrepancy in the three frozen brane loads: 8.6736173798840355e-19 in solver force units. Four analytically integrated Wolfram probe values agree with the archived Python quadrature at its printed precision. The step response and force-derivative series also agree: g^(5)(0)/480 equals c5/4 when c5 is the fifth Taylor coefficient.
