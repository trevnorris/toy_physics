## 1. The pivot — from force-first audit to medium-first generative

**What we have been doing (force-first / requirements-inversion).** For each force we asked *"what does it need, and can we extract it from a fixed medium?"* This was **diagnostic** — it mapped the graveyard (mechanical-mode EM → `B_eff→0` / second-class / scalar-attraction-only). But it is **not generative**: it drives us to bolt a mechanism onto each force one at a time (the Requirement-A "unearned bolt-on" worry is exactly this symptom), and it never yields a single object that *produces* everything.

**The pivot (medium-first / generative).** Specify the **one medium's substructure** as richly and honestly as we can — constituents, their internal DOF, the brane as their collective ordered state, the throat — and then **compute the excitation/mode spectrum and read off the forces**. The forces are consequences, not insertions. This is how the emergent programs that actually work operate (Volovik ³He-A: one order parameter → chiral fermions + gauge field + effective metric, none inserted), and — per the user — **it is how this program itself started** (the substructure reasoning that produced the `n=5` EOS, our first calibration).

**This is the program's own founding method, recovered — not a new idea.** `conceptual_foundation.md` already legislates it:
- **§1 (substructure lens):** *"when an interaction... doesn't make sense, the resolution may be that we haven't yet defined the superfluid's substructure richly enough. Treat a puzzle in the emergent physics as a hint about the constituents."* → **the EM wall is that hint.**
- **§0.6 (analog, not derivation):** postulate the substructure **freely**; the test is **internal consistency**; do **not** chase the sub-medium bottom (the constituents "could be 4D structures in their own 5D space — unknowable"). → **this bounds the pass:** we enrich the medium's *description*, we do not build a 5D parent.
- **§0.1 (one medium, everything emergent):** if the math starts looking like "the medium **plus** a separate gauge field on its own metric," that is **drift, to be pruned**. → an emergent EM must be a *mode of the medium*, not an added field.

**The value proposition (the user's, banked):** a medium that merely **reproduces** known laws is uninformative — you can always fit. A medium that yields **the laws PLUS a characterized extra** (an unforced additional mode, coupling, or departure) is **useful and falsifiable**. We *want* the extra. A clean "it all just works, nothing extra" is the suspicious outcome (§0.4). The program already has a track record of exactly these extras — the `h`-branon charge-coupled scalar (pathA_39/42), the breathing-drain monopole radiation (pathA_29), the falsified 1:9:25 mass tower, the bulk↔brane dark-energy cycle (§5).
