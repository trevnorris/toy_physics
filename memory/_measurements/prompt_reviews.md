# Semantic Prompt Review Record

Date: 2026-08-24
Artifact: `memory/prompts/` and the corresponding schema contract
Method: two independent read-only review legs, followed by one fold

## Evidence/claim-safety leg

The first leg blocked use of the original prompts for seven reasons:

- live repository access was prohibited in prose but not absent;
- topic/conflict synthesis could reuse an `ai_draft` paraphrase without direct
  source bytes;
- `measured` allowed code or a report in place of an exact invocation and
  literal operands/residual;
- resolved conflicts could retain a contradictory aggregate `disputed` label;
- substantive claims outside `Key statements` could lack statement status;
- anchor-less claims could still receive strong evidence labels;
- output size and memory-dependency freshness were subjective/underspecified.

The leg also verified strong identity-only handling, conservative precedence,
explicit PASS/comparator limitations, scoped supersession, generated-region
ownership, and `ai_draft` defaults.

## Operational-interface leg

The second leg independently confirmed the hard-boundary defect and found that
writer tasks lacked required page/unit metadata, derived-task producers,
deletion/retirement history, stable-ID allocation, mixed-page base protection,
an index type, objective budgets, and consistent citation/role handling.

## Fold

The authoritative prompt/schema fold added:

- a Gitless OS-isolated writer contract with a pre-run isolation contract and
  trusted post-run attestation;
- self-contained task metadata, frozen prompts/schema, stable-ID registries,
  prior lifecycle/member history, and dependency freshness identities;
- target-commit direct source bytes/excerpts for every load-bearing topic or
  conflict statement;
- exact invocation + readable literal operands/residual + separate
  interpretation for `measured`;
- status blocks for every substantive statement and page-namespaced IDs;
- `anchor-unavailable` as the only fallback, prohibited for `measured` and
  `derived`;
- state-specific conflict positions and dispositions;
- hard word/statement/entry budgets;
- explicit deletion/retirement prompt routing;
- structured per-item Atlas migration records.

No semantic research pages were generated before this fold.
