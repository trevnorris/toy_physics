Damped dressing-leg correction for the reduced same-charge cold crossing
============================================================================================

Scope
--------------------------------------------------------------------------------------------
This run keeps the same reduced lowered-barrier branch used in the earlier
dynamic/helicity continuation. The cold event is fixed at v0 = 2.6 on the
aligned-spin branch, which still crosses the lowered barrier while pure Coulomb
turns back. The only new ingredient is Langevin-style shedding on the V-leg.

Symbolic formulas used
--------------------------------------------------------------------------------------------
t_cross(E)         = sqrt(2)*lambda_eff*sqrt(m_s)*sqrt(1/(E - V_peak))/2
t_cross(v0)        = lambda_eff*sqrt(m_s)*sqrt(1/(2*V0 - 2*V_peak + m_s*v0**2))
gamma_crit         = sqrt(chi_peak)*sqrt(g_UV)/sqrt(mu_eta)
t_collapse^damped  = Piecewise((1/(gamma_crit - gamma_tot), gamma_crit > gamma_tot), (oo, True))
gamma_safe(v0)     = gamma_crit - 1/(lambda_eff*sqrt(m_s)*sqrt(1/(2*V0 - 2*V_peak + m_s*v0**2)))
E_diss             = gamma_tot*mu_eta*Integral(Vdot(t)**2, (t, 0, t_cross))
E_vac              = gamma_vac*mu_eta*Integral(Vdot(t)**2, (t, 0, t_cross))
E_lattice          = gamma_lattice*mu_eta*Integral(Vdot(t)**2, (t, 0, t_cross))

Bottom line
--------------------------------------------------------------------------------------------
1) On the corrected damped-envelope branch, the cold v0 = 2.6 event is not
   safe when the V-leg is treated as a perfect trap: the undamped ratio S is
   far above one.
2) A finite shedding window now exists. The cold event becomes stable once
   gamma_tot exceeds gamma_safe, and it becomes unconditionally stable once
   gamma_tot reaches gamma_crit.
3) With the default 3:1 lattice-to-vacuum split, the lattice takes 75% of the
   dissipated dressing-leg energy. The threshold-event lattice heat per crossing
   is therefore the E_lattice value quoted above.
