Dynamic continuation of the relaxed same-charge barrier stress test
==============================================================================

Scope
------------------------------------------------------------------------------
This is a reduced continuation of the earlier stationary U/V + leakage +
sign-changing-source closure. It is not a solved moving-throat PDE theorem.
The dynamic barrier side is kept on the same short-range-family branch as the
same-charge barrier audit, while the magnetic/helicity side uses the exact
canonical-vorticity and projected/subscale-helicity identities as the structural
anchors and closes the unresolved mixed correlations phenomenologically.

Representative symbolic formulas
------------------------------------------------------------------------------
Xi_1 = (-delta_ln_R_target*(epsilon_eta_star - 1) + delta_ln_epsilon_eta*epsilon_eta_star)/(epsilon_eta_star - 1)
Omega_ij = -F_ij*q_s/m_s
P_WKB ~ exp(-2*I_WKB/hbar_eff)
lambda_th(r_turn) = Abs(V_eff(r)/Derivative(V_eff(r), r))
dh_sub/dt (local source term) = -2*Eprime_dot_Bprime

Task 3 — threshold equation for lambda
------------------------------------------------------------------------------
Operational definition used here:
  chi_lambda(r) := lambda * |d ln(V_eff)/dr|
so the threshold for beyond-MHD behavior at a turning point is
  lambda_th(r_turn) = 1 / |d ln(V_eff)/dr|_(r_turn)
                    = |V_eff(r_turn) / V_eff'(r_turn)|.

Bottom line
------------------------------------------------------------------------------
1) The lowered reduced barrier admits a finite classical threshold that is absent
   in pure Coulomb, and the default subbarrier slice gives a >20% WKB enhancement
   in reduced units.
2) The magnetic/helicity sector prefers aligned spins for access to the pure-transfer
   subcorridor on the present reduced closure.
3) The confinement-width trigger is now explicit as lambda_th(r_turn), so the
   branch can be read directly as a laboratory steepness requirement once a
   physical unit map for r is chosen.
