Proton-proxy structural-stability sweep for the lowered same-charge barrier
========================================================================================

Scope
----------------------------------------------------------------------------------------
This script keeps the same reduced stationary branch used in the earlier
relaxed-constraint and dynamic/helicity runs, then overlays the requested
proton-proxy mass/inertia scaling and the new crossing-vs-collapse timescale test.
The aligned-spin closure stays active for the dynamic transit cross-check.

Symbolic formulas used
----------------------------------------------------------------------------------------
t_cross(E)    = sqrt(2)*lambda_eff*sqrt(m_s)*sqrt(1/(E - V_peak))/2
t_collapse    = sqrt(mu_eta)/(sqrt(chi_peak)*sqrt(g_UV))
S(E)          = sqrt(2)*sqrt(chi_peak)*sqrt(g_UV)*lambda_eff*sqrt(m_s)*sqrt(1/(E - V_peak))/(2*sqrt(mu_eta))
E_edge        = V_peak + chi_peak*g_UV*lambda_eff**2*m_s/(2*mu_eta)

If the heavy throat scales as mu_eta = alpha * m_s, these reduce to
S(E)          = sqrt(2)*sqrt(chi_peak)*sqrt(g_UV)*lambda_eff*sqrt(1/(E - V_peak))/(2*sqrt(alpha))
E_edge        = V_peak + chi_peak*g_UV*lambda_eff**2/(2*alpha)

Bottom line
----------------------------------------------------------------------------------------
1) With the proton-proxy scaling m_s = mu_eta = m_p/m_e and the earlier trigger
   width lambda_th kept as the active barrier width, the characteristic stability
   boundary lands at E_inc ≈ 5.32266 in the same reduced units.
2) No upper collapse edge appears before the top of the scanned hot branch, so the
   mathematically permitted region is one-sided rather than a closed island on this closure.
3) The actual aligned-spin barrier-region transit is even shorter than the requested
   characteristic estimate, so the conservative stability window is not being overstated.
