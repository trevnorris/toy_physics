# 4D 2.5PN Mathematica Archive

The paper-supportive Wolfram verification layer has two levels.

- `2_5pn_master_mathematica_audit.wl` is the compact referee-facing harness for the core theorem chain: benchmark, low-frequency bookkeeping, scalar/dipole demotion, and the surviving quadrupole branch.
- `2_5pn_master_session_mathematica_audit.wl` is the session-completion superset that carries the same chain through the quadrupole-normalization package.

The official manifest for the paper-facing Wolfram suite is `wl_notes.txt`.
