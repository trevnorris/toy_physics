2. Reflection/transmission from a load impedance
========================================================================================

For pressure p and volume flow Q at the tube end:
  p = p_in + p_ref,
  Q = (p_in/Z_t) - (p_ref/Z_t),
  p = Z_L Q.
Let eps = Z_L/Z_t. Sudden expansion / low acoustic load has eps << 1.
  Pressure/potential amplitude reflection R_p(eps) = (eps - 1)/(eps + 1)
  Pressure/potential amplitude transmission T_p=1+R_p = 2*eps/(eps + 1)
  Flow/displacement amplitude reflection R_q=-R_p = (1 - eps)/(eps + 1)
  Flow/displacement amplitude transmission T_q=1+R_q = 2/(eps + 1)
  Energy reflection coefficient |R|^2 = (eps - 1)**2/(eps + 1)**2
  Energy transmission coefficient = 4*eps/(eps + 1)**2

Low-load / sudden-expansion series eps -> 0:
  R_p: -1 + 2*eps - 2*eps**2 + 2*eps**3 + O(eps**4)
  T_p: 2*eps - 2*eps**2 + 2*eps**3 + O(eps**4)
  R_q: 1 - 2*eps + 2*eps**2 - 2*eps**3 + O(eps**4)
  T_q: 2 - 2*eps + 2*eps**2 - 2*eps**3 + O(eps**4)
  E_ref: 1 - 4*eps + 8*eps**2 - 12*eps**3 + O(eps**4)
  E_trans: 4*eps - 8*eps**2 + 12*eps**3 + O(eps**4)

Area-expansion model: chi = A_eff/A_t >> 1, eps ~= 1/chi.
  R_p(chi) = (1 - chi)/(chi + 1)
  R_q(chi) = (chi - 1)/(chi + 1)
  T_energy(chi) = 4*chi/(chi + 1)**2
  R_p large-chi via delta=1/chi: -1 + 2*delta - 2*delta**2 + 2*delta**3 + O(delta**4)
  R_q large-chi via delta=1/chi: 1 - 2*delta + 2*delta**2 - 2*delta**3 + O(delta**4)
  T_energy large-chi via delta=1/chi: 4*delta - 8*delta**2 + 12*delta**3 + O(delta**4)
