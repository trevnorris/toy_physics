## 1. Exact parent compensation-defect scalar

Define the exact parent compensation function
\[
\boxed{
\mathcal F(\mathfrak g,\mathfrak r)
:=
1+\mathfrak r^2-4(\mathfrak g-\mathfrak r)^2.
}
\]
Then
\[
\mathcal F=0
\]
is exactly the parent compensation family of Stage 119.

On the lower branch,
\[
\mathfrak g_-(\mathfrak r)
=
\mathfrak r-\frac12\sqrt{1+\mathfrak r^2},
\]
with slope
\[
\boxed{
\mathfrak g_-'(\mathfrak r)
=
1-\frac{\mathfrak r}{2\sqrt{1+\mathfrak r^2}}.
}
\]

Now define the first off-family normal coordinate by
\[
\boxed{
\delta_\perp
:=
\delta\mathfrak g
-
\mathfrak g_-'(\mathfrak r_*)\,\delta\mathfrak r.
}
\]
This vanishes for every infinitesimal motion tangent to the lower compensated parent family, and only measures true normal drift away from that family.

Linearizing \(\mathcal F\) on the lower branch gives the exact identity
\[
\boxed{
\delta\mathcal F
=
4\sqrt{1+\mathfrak r_*^2}\,\delta_\perp.
}
\]
So \(\delta_\perp\) is literally the normalized first-order parent compensation defect.

## 3. Exact microscopic formula for the off-family scalar

The normalized parent ratios are
\[
\mathfrak r=\frac{\lambda}{\sqrt{K_sK_q}},
\qquad
\mathfrak g=\frac{g_q\sqrt{K_s}}{g_s\sqrt{K_q}}.
\]
So their first logarithmic variations are
\[
\delta\mathfrak r
=
\mathfrak r_*
\left(
\delta\ln\lambda
-\frac12\delta\ln K_s
-\frac12\delta\ln K_q
\right),
\]
\[
\delta\mathfrak g
=
\mathfrak g_*
\left(
\delta\ln g_q
-\delta\ln g_s
+\frac12\delta\ln K_s
-\frac12\delta\ln K_q
\right).
\]

Substituting into the definition of \(\delta_\perp\) and simplifying gives the exact microscopic residual
\[
\boxed{
\delta_\perp
=
\mathfrak g_*\,
\delta\ln\!\left(\frac{g_qK_s}{g_s\lambda}\right)
+
\frac{1}{4\sqrt{1+\mathfrak r_*^2}}\,
\delta\ln\!\left(\frac{K_sK_q}{\lambda^2}\right).
}
\]

This is the cleanest result of the stage.

It says the first true off-family drift is generated by exactly two logarithmic microscopic imbalance channels:

   \delta\ln\!\left(\frac{g_qK_s}{g_s\lambda}\right),

   \delta\ln\!\left(\frac{K_sK_q}{\lambda^2}\right).

So the vague statement “the true branch may leave the exact parent family” has now been reduced to one explicit parent-action scalar.
