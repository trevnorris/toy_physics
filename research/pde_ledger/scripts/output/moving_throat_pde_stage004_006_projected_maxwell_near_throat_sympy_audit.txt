1) Exact projected inhomogeneous Maxwell law on a throat domain
================================================================================================
Take the generalized weighted bulk equation
  ∂_M(Z F^{MN}) + (1/ξ) ∂^N(H B) = μ0 J^N
and project a brane component ν over a throat interval D ⊂ w using a normalized kernel W(w):
  <Q>_W := ∫_D W(w) Q(w) dw,     ∫_D W(w) dw = 1.

Integrating the w-derivative by parts gives the exact projected law
  ∂_μ <Z F^{μν}>
  + [ W Z F^{wν} ]_{∂D}
  - < W' Z F^{wν} >
  + (1/ξ) ∂^ν <H B>
  = μ0 <J^ν>.

Equivalently, by recombining the boundary and W'-term,
  ∂_μ <Z F^{μν}> + < ∂_w(Z F^{wν}) > + (1/ξ) ∂^ν <H B> = μ0 <J^ν>.

This form is exact on a finite throat interval or a half-line throat chart.
The mixed-sector derivative term <∂_w(Z F^{wν})> is the part that disappears in the far-field zero-mode limit.

2) Symmetric narrow-kernel expansion around an interior slice
================================================================================================
For an even normalized kernel W_σ(w) centered at an interior slice w0, odd moments vanish.
Writing Q(w0+σu) in a Taylor series, the exact moment expansion begins
  <Q>_σ = m2*q2*sigma**2/2 + m4*q4*sigma**4/24 + q0
  <∂_w Q>_σ = m2*q3*sigma**2/2 + m4*q5*sigma**4/24 + q1

So the projected Maxwell equation near an interior slice is
  ∂_μ[ M0^{μν} + (m2 σ^2/2) M2^{μν} + O(σ^4) ]
  + [ Q1^ν + (m2 σ^2/2) Q3^ν + O(σ^4) ]
  + (1/ξ) ∂^ν[ G0 + (m2 σ^2/2) G2 + O(σ^4) ]
  = μ0 [ J0^ν + (m2 σ^2/2) J2^ν + O(σ^4) ],
where M^{μν}=Z F^{μν},  Q^ν=Z F^{wν},  G=H B.

Important consequence: for a symmetric observer kernel, the first projection-width corrections are even, O(σ^2).

3) One-sided mouth kernel: exact boundary cancellation and local throat expansion
================================================================================================
Choose the normalized mouth-anchored kernel on the half-line w ≥ 0
  W_ell(w) = exp(-w/ell)/ell.

For a smooth Q(w) at the mouth, SymPy gives
  <Q>_ell = ell**4*q4 + ell**3*q3 + ell**2*q2 + ell*q1 + q0
  <∂_w Q>_ell = ell**3*q4 + ell**2*q3 + ell*q2 + q1

If we keep the boundary split, the two pieces are
  [W Q]_{0}^{∞} = -q0/ell
  -<W' Q>       = ell**3*q4 + ell**2*q3 + ell*q2 + q1 + q0/ell
and they recombine exactly to
  [W Q]_{0}^{∞} - <W' Q> = ell**3*q4 + ell**2*q3 + ell*q2 + q1

So the apparent 1/ell boundary singularity cancels.
The mouth-local projected derivative is finite and expands as
  <∂_w Q>_ell = q1 + ell q2 + ell^2 q3 + ell^3 q4 + ...

Therefore the near-mouth projected Maxwell equation is
  ∂_μ[ M0^{μν} + ell M1^{μν} + ell^2 M2^{μν} + ... ]
  + [ Q1^ν + ell Q2^ν + ell^2 Q3^ν + ... ]
  + (1/ξ) ∂^ν[ G0 + ell G1 + ell^2 G2 + ... ]
  = μ0 [ J0^ν + ell J1^ν + ell^2 J2^ν + ... ].

Important consequence: at the mouth, asymmetry turns the first width correction into O(ell), not O(σ^2).

4) Zero-mode effective parameters in the near-throat limits
================================================================================================
Now impose the zero-mode ansatz
  A_μ(x,w)=a_μ(x),   A_w=0,   F^{wν}=0,   J^ν(x,w)=j^ν(x) S(w).
Then the projected equation becomes
  <Z> ∂_μ f^{μν} + (<H>/ξ) ∂^ν(∂·a) = μ0 <S> j^ν,
so the local effective parameters are
  μ_eff = μ0 <S>/<Z>,    ξ_eff = ξ <Z>/<H>.

Symmetric interior kernel (first nontrivial correction O(σ^2)):
  μ_eff^(sym) = mu0*s0/z0 + sigma**2*(-m2*mu0*s0*z2/(2*z0**2) + m2*mu0*s2/(2*z0))
  ξ_eff^(sym) = sigma**2*(m2*xi*z2/(2*h0) - h2*m2*xi*z0/(2*h0**2)) + xi*z0/h0

One-sided mouth kernel (first correction O(ell)):
  μ_eff^(mouth) = ell*(-mu0*s0*z1/z0**2 + mu0*s1/z0) + mu0*s0/z0
  ξ_eff^(mouth) = ell*(xi*z1/h0 - h1*xi*z0/h0**2) + xi*z0/h0

So the first mismatch measures local shape-slippage:
  symmetric: (S2/S0 - Z2/Z0) and (Z2/Z0 - H2/H0),
  mouth:     (S1/S0 - Z1/Z0) and (Z1/Z0 - H1/H0).

Immediate corollaries:
  - If H = Z, then ξ_eff = ξ exactly, not just approximately.
  - If S is locally proportional to Z at the mouth/interior slice, the first μ_eff correction vanishes.

Exact profile-alignment checks:
  if S = C Z globally, then μ_eff = C*mu0
  if H = Z globally, then ξ_eff = xi

6) PDE reading of the result
================================================================================================
Near the throat, projection-first Maxwell does NOT collapse immediately to the far-field brane law.
The leading extra structure is the mixed-sector derivative term
  <∂_w(Z F^{wν})>,
which survives exactly on the throat domain and is lost only when the far-field zero-mode suppressions
  F_{μw} ≈ 0,   J^w ≈ 0,   ∂_w A_μ ≈ 0
are imposed.

This is why the near-throat limit is a better match to the moving-throat PDE language:
the Maxwell/mixed block contributes local transverse-gradient data before any reduction to ordinary 3+1 Maxwell.

The main structural distinction is:
  - symmetric interior observation  -> first width correction O(σ^2),
  - mouth-anchored observation     -> first width correction O(ell).

So the mouth itself is the place where projection-first and reduction-first differ most sharply.
That makes it the natural regime to compare against the moving-throat Maxwell/mixed bundle.
