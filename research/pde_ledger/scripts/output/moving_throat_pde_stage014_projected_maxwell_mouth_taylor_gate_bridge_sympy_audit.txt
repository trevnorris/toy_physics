================================================================================================
1) Mouth-local Taylor ansatz
================================================================================================
Take a normalized one-sided mouth kernel w(u), u >= 0, with first moment mu1 = ∫ u w(u) du.
Then for any primitive one-port quantity X(s),
  X_proj(ell) = X(0) + ell * mu1 * X'(0) + O(ell^2).
So
  q1 = mu1*Q'(0),   s1 = mu1*S2'(0),   h1 = mu1*H_port'(0),
  d1 = mu1*Delta'(0).
For a symmetric interior kernel, mu1 = 0 and the whole first layer vanishes.

================================================================================================
2) Primitive-to-bundle mouth-derivative map (divide out mu1)
================================================================================================
z0/mu1 =
  (Delta*Qx - Deltax*Q)/Delta**2
z2/mu1 =
  -(Delta**2*Hx - Delta*Deltax*H - Delta*Q*S2x - Delta*Qx*S2 + 2*Deltax*Q*S2)/Delta**3
z4/mu1 =
  -(Delta**2*H*S2x + Delta**2*Hx*S2 + Delta**2*Qx - 2*Delta*Deltax*H*S2 - 2*Delta*Deltax*Q - 2*Delta*Q*S2*S2x - Delta*Qx*S2**2 + 3*Deltax*Q*S2**2)/Delta**4

================================================================================================
3) Direct projected-Maxwell contribution to the 5PN even gates
================================================================================================
K1^(proj)/mu1 =
  (9*Delta**2*Hx - Delta**2*Qx - 9*Delta*Deltax*H + Delta*Deltax*Q - 9*Delta*Q*S2x - 9*Delta*Qx*S2 + 18*Deltax*Q*S2)/(9*Delta**3)
H_even^(proj)/mu1 =
  -(18*Delta**3*Hx + Delta**3*Qx - 18*Delta**2*Deltax*H - Delta**2*Deltax*Q - 27*Delta**2*H*S2x - 27*Delta**2*Hx*S2 - 18*Delta**2*Q*S2x - 18*Delta**2*Qx*S2 - 27*Delta**2*Qx + 54*Delta*Deltax*H*S2 + 36*Delta*Deltax*Q*S2 + 54*Delta*Deltax*Q + 54*Delta*Q*S2*S2x + 27*Delta*Qx*S2**2 - 81*Deltax*Q*S2**2)/(27*Delta**4)

Immediate dependency pattern:
  - K1 and H_even depend only on (Q', Delta', S2', H_port').
  - P' and G_W' do not enter K1 or H_even.


================================================================================================
4) Mechanism sieve
================================================================================================
Case A: source/denominator sector only, S2' = H_port' = 0
  solve K1 = H_even = 0  ->
   [{Deltax: 0, Qx: 0}]
Case B: spectral sector only, Q' = Delta' = 0
  solve K1 = H_even = 0  ->
   [{Hx: 0, S2x: 0}]

So neither a pure (Q', Delta') correction nor a pure (S2', H_port') correction
can close the even gates nontrivially.

================================================================================================
5) Exact mixed compensation surface for the even gates
================================================================================================
Solving K1 = H_even = 0 for (H_port', S2') gives
H_port' =
  (Delta**3*H*Qx + Delta**3*Q*Qx + 9*Delta**2*Deltax*H**2 - Delta**2*Deltax*H*Q - Delta**2*Deltax*Q**2 + 9*Delta**2*H*Qx*S2 - 2*Delta**2*Q*Qx*S2 - 9*Delta**2*Q*Qx - 18*Delta*Deltax*H*Q*S2 + 2*Delta*Deltax*Q**2*S2 + 18*Delta*Deltax*Q**2 - 9*Delta*Q*Qx*S2**2 + 9*Deltax*Q**2*S2**2)/(9*Delta**2*(Delta*H - Q*S2))
S2' =
  (Delta**3*Qx - Delta**2*Deltax*Q - Delta**2*Qx*S2 - 9*Delta**2*Qx + 9*Delta*Deltax*H*S2 + Delta*Deltax*Q*S2 + 18*Delta*Deltax*Q - 9*Deltax*Q*S2**2)/(9*Delta*(Delta*H - Q*S2))

The compensation denominator is proportional to
  Delta*H_port - Q*S2.
This is exactly the primitive combination behind the conservative Z2 slot:
  Z2 = (Q*S2 - H_port*Delta)/Delta^2.
So the even-gate compensation becomes singular on the surface Delta*H_port = Q*S2
(equivalently Z2 = 0).

================================================================================================
6) Readout
================================================================================================
The mouth-local projected-Maxwell packet repairs the conservative even gates K1 and H_even
through the primitive slopes (Q', Delta', S2', H_port') when the compensation denominator is nonzero.
