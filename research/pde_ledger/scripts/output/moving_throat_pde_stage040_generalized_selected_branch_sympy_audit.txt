========================================================================================
STAGE 23 THEOREM LEDGER
========================================================================================
1. Once source and loading vectors differ, the Stage-18 normalization function deforms
   from the single-vector form F(xi,delta) to the exact two-vector function
      F_(q,eta)(xi,delta).
2. The required baseline loading is still exact and one-dimensional:
      G_q(xi,delta) = xi (xi+delta) / [delta + (1+q^2) xi].
3. For the split-U continuum, the source/loading mismatch collapses to one exact
   parameter R_U through
      q = -(sqrt(2)/3) R_U,  eta = (2/9) R_U.
4. Setting R_U = 1 recovers the Stage-18/19 flat-U branch exactly.
5. Therefore the first non-flat U structure does not destroy the selected-branch
   theorem geometry, but it deforms it into a one-parameter family indexed by R_U.
