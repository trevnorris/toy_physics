
========================================================================================
STAGE 37 — ROBIN-COMPLIANCE SOFTENING
========================================================================================
B from Neumann bottom = A*tan(L*k)
Robin characteristic equation factor = -h + k*tan(L*k)
Robin equation -> k tan(kL) - h = 0
dimensionless form = 0

========================================================================================
EXACT SOFTENING FACTOR
========================================================================================
K_W^(eff) = K_X + pi**2*T_X/(4*L**2)
K_phi,0^(eff) = K_X + T_X*y**2/L**2
A_K = (K_X*L**2 + pi**2*T_X/4)/(K_X*L**2 + T_X*y**2)
x definition: Eq(x, pi**2*T_X/(K_W*L**2))
K_W identity = 0
A_K in x,y form = 4*pi**2/(4*x*y**2 - pi**2*(x - 4))
A_K x-form = 0
A_K(y=pi/2) = 1
A_K(y->0+) = -4/(x - 4)
DN limit = 0
soft-mouth limit = 0

========================================================================================
PURE SOFTENING THRESHOLD
========================================================================================
Condition A_K >= zeta_req implies y^2 <= pi**2*(zeta_req*(x - 4) + 4)/(4*x*zeta_req)
A_K,max = -4/(x - 4)
x floor at saturation = 4 - 4/zeta_req
x floor = 4 - 4/zeta_req = 0

FINAL LEDGER
  Robin compliance replaces the D/N half-wave by y tan y = eta.
  The support softening factor is A_K = 1 / [1 - x/4 + x y^2/pi^2].
  It ranges from 1 up to 4/(4-x).
  Pure softening rescue is possible only if zeta_req <= 4/(4-x).
