STAGE 092 — DYNAMIC-GEOMETRY OBSTRUCTION
========================================================================================
K_Q^cons(omega) = (K_p*Omega_Q**2 + (Omega_Q**2 - omega**2)*(K_g0 + K_g2*omega**2 + K_g4*omega**4))/(Omega_Q**2 - omega**2)
Series = K_g0 + K_g2*omega**2 + K_g4*omega**4 + K_p + K_p*omega**2/Omega_Q**2 + K_p*omega**4/Omega_Q**4
K0 = K_g0 + K_p
K2 = K_g2 + K_p/Omega_Q**2
K4 = K_g4 + K_p/Omega_Q**4
Branch obstruction = ((K_g0 + K_p)*(K_g4*Omega_Q**4 + K_p) - 4*(K_g2*Omega_Q**2 + K_p)**2)/Omega_Q**4
K_g0 on branch = (4*K_g2**2*Omega_Q**4 + 8*K_g2*K_p*Omega_Q**2 - K_g4*K_p*Omega_Q**4 + 3*K_p**2)/(K_g4*Omega_Q**4 + K_p)
static-geometry limit gives 3 K_pole = 0
c_pole = K_p*(K_g4*Omega_Q**4 + K_p)/(4*(K_g2*Omega_Q**2 + K_p)**2)
c_pole in (eps2, eps4) variables = (eps_4 + 1)/(4*(eps_2 + 1)**2)
c_pole - (1+eps4)/(4(1+eps2)^2) = 0
c_geom in (eps2, eps4) variables = (4*eps_2**2 + 8*eps_2 - eps_4 + 3)/(4*(eps_2 + 1)**2)
First-order expansion of c_pole = -eps_2*eps_4/2 - eps_2/2 + eps_4/4 + 1/4
Linear part                = -eps_2/2 + eps_4/4 + 1/4
Dropped higher-order tail  = -eps_2*eps_4/2
first-order eps^0 coefficient = 0
first-order eps2 coefficient = 0
first-order eps4 coefficient = 0

========================================================================================
FINAL LEDGER
========================================================================================
With dynamic geometry contamination,
  c_pole = (1 + eps4) / [4 (1 + eps2)^2].
So the 3/4 + 1/4 split is recovered iff eps2 = eps4 = 0.
