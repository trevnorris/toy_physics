STAGE 181 LEDGER
========================================================================================
1. The exact coherent monomials are triangular in the dependent microscopic triple
      (T_U, K_eta^(eff), mu_W),
   so for fixed free microscopic coordinates and fixed invariant triple
      (Ctr_*, Cnt_*, epsEta_*),
   the dependent triple is determined uniquely by
      K_eta^(orbit) = c_etaU^2 / (K_U epsEta_*),
      T_U^(orbit)   = (L^2 K_U / pi^2) [Ctr_* / (gamma c_etaU / K_U)^(1+deltaU_*)]^(1/(1+chi0_*)),
      mu_W^(orbit)  = Cnt_* K_eta^(orbit) K_W^2 / lambda_W^2 * (gamma^2 lambda_W^2 sigma / (K_U K_W))^(-E_*) * (pi^2 T_U^(orbit)/(L^2 K_U))^(F_*).
2. A candidate branch with the same five free microscopic coordinates is therefore compared to the orbit point by the exact dependent residual mismatch ratios
      T_U = m_T T_U^(orbit),   K_eta^(eff) = m_K K_eta^(orbit),   mu_W = m_mu mu_W^(orbit).
3. The invariant ratios are exactly
      Ctr(actual)/Ctr(orbit) = m_T^(1+chi0_*),
      epsEta(actual)/epsEta_* = 1/m_K,
      Cnt(actual)/Cnt(orbit) = m_mu / (m_K m_T^(F_*)).
4. Writing tau = ln m_T, kappa = ln m_K, mu = ln m_mu, the Packet-B quotient coordinates are exactly
      q_tr = (1+chi0_*) tau,   q_eta = -kappa,   q_nt = mu - kappa - F_* tau.
   Applying the Stage 192 drift compiler M_* to a pure dependent mismatch vector reproduces this chart exactly.
5. Restoration to the same orbit changes only the dependent triple:
      T_U^(restore)   = T_U exp[-q_tr/(1+chi0_*)],
      K_eta^(restore) = K_eta exp[q_eta],
      mu_W^(restore)  = mu_W exp[-q_nt + q_eta - F_* q_tr/(1+chi0_*)].
6. Therefore the finite orbit-lock condition is exactly
      m_T = m_K = m_mu = 1  <=>  q_tr = q_nt = q_eta = 0.
   This is the exact Packet-B complement of the Stage 197 Packet-A finish-line theorem.
