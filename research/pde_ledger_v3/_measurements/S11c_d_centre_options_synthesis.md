mechanics, a centre solver and a general uniqueness/spectrum investigation.

balance too broad a prerequisite for every retained observable. The stronger
general claim remains unsupported, but it need not block all work on the
specified thickness-sector scattering problem.

## Real disagreements and my judgment

**Does the supplied model literally give a massless centre constraint?**
Claude says a literal free variation of the stated energy/work would do so,
but doubts whether that was the intended model given the centre-fixed
ancestry. Grok says the supplied internal-field balance does not contain a
centre law to finish. I would not settle this ambiguity by treating the
omission as a supplied zero mass. Their shared recommendation avoids needing
that model decision for a justified restricted observable.

**Is reflection already enough?** Claude proposes deriving a complete
covariance lemma; Grok is content to retain the particular-problem label.
The source supports a targeted check, not an automatic universal lemma.
I checked Claude's specific caveat: a §3c defines a smooth two-argument
window `O(G_plus,G_minus)` but does not explicitly require symmetry under
argument exchange. That matters only if this window reaches the claimed
operator/current/normalization. We should trace that actual dependency, not
assume symmetry and not treat every upstream window as an obstruction to
every end-channel quantity. No new algebra was done in this consultation.

**What about bulk power?** I qualify Claude's broad statement that even
observables do not depend on homogeneous odd additions. Decoupling can protect
a projected even linear response. A quadratic total flux can still contain
the odd field's own power even when even/odd cross terms vanish; cancellation
of cross terms also requires the relevant pairing and integration domain.
The selected incident/response sector and the observable must therefore be
explicit. Neither report establishes total bulk leakage for arbitrary centre
motion. Grok's particular-solution qualification is the safer starting point.

## Recommended next work for the user's decision

1. **One bounded source/claim disposition, with no new numerical run:** state
   which incident sector and particular response the existing five-field
   data describe, and the exact end-channel and face-drive claims proposed.
   For any stronger reflection-invariant-sector claim, check the actual
   reverse coupling and relevant source/measure/window premises. A source
   proof can suffice; no general centre spectrum is prescribed.
2. **Then resume supported bindable FORM/export construction**, under its
   applicable build gate, carrying the actual qualifications. Do not repeat
   the completed centre diagnostic or reopen the amendment for cosmetic
   changes. If the limited source check finds a real missing premise, name
   it once and return that specific decision; do not create a diagnostic chain.
3. **Keep the radiating-domain decision separate.** The finite decaying-bulk
   method does not supply nonempty radiating support or continuous-spectrum
   coverage. Centre-sector reasoning does not remove that obstacle. The
   general A9/A11/A12 package is still incomplete; no reduced result is
   silently relabelled as satisfying it. Existing export, independent review,
   blind Wolfram and scoped T7 duties remain.

The practical conclusion is to stop treating a general centre model as the
next automatic project. Both advisers see a much smaller way to state and,
where needed, justify the retained scattering sector. The user decides whether
to proceed with this bounded route. No choice is adopted by this report.
