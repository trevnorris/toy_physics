# Packet map and evidence boundary

`method.md` is the new proposal. `packet-index.json` supplies the exact source
hash and selection rule for every file; metadata projections do no algebra.
No old peer reports, peer commentary or credentials are included.

Read `selected/pressure-addresses.json` for ALL 544 e_W-source entries in the
actual THETA row, including 442 saved zero entries and 102 formal entries.
`selected/local-cells.json` supplies all 16 local derivative/grade cells for
the same block. Their full original source file receipts and selection predicates
are recorded. A later worker must restore/join the full source inventories; these
projections neither recompute their identities nor assert numerical nonzero values.

`pressure/fields.json` and `pressure/coefficient-certificates.json` provide the
actual polynomial fields. `pressure/whole-tags.json`, `pressure/typed-direct.json`
and `pressure/whole-definitions.json` fix the actual H, J and direct objects and
argument conventions. The pressure/normal global envelopes, height-PV certificates,
native source jets and Fourier-order record are under `pressure/`.

`local/context.json` and `local/assembly.json` join the same physical input and
native local/pressure partition. `physical-input.json` remains the original
development input; no primitive speed calibration is inferred.
`ends/left-match.json` is the actual saved positive matching point and closed
comparison. Its inherited current objects are historical; this proposal does
not transfer them. `ends/correspondence-summary.json` is a compact source/result
metadata projection with all reviewer material omitted.

`background/pressure-weak-method.md` and `background/full-weak-method.md` contain
the assessed defining weak formulas and bounds being inherited. They are not
new results. `source/composition.py`, `source/pressure-weak.py`, `source/full-weak.py`
and `source/weak-ends.py` are original instruments for source interfaces only;
none is to be executed or replayed. `source/legacy-integration.py` and
`source/legacy-finite.py` are comparison-route background: the old cs=10 numerical
arrays do not become near-unity references. No old full matrix is proposed.

This packet is method-only. There is no new worker, manifest, execution gate or
computed weak action. A clear verdict supports bounded build preparation, not
automatic result acceptance or a scattering/loss claim.
