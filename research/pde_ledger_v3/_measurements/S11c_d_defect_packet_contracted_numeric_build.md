# Concrete bounded numerical J/direct evaluator

2026-10-04. Proposed source build. No scientific execution or READY gate exists.
The unchanged numerical method is supplied as `method.md`. This implementation
computes only ordinary J and the three ADDED direct primitives for the two original
Gaussian carriers, on K27/T122 and K29/T124. H, flat, height/contact/PV, slope and
their controls remain pending. J is not full native mixed; J+D is not a packet
value, current or leakage factor. No completed source, profile, response, grade,
unit, rule, geometry or numerical bank function is invoked.

The 3,142 complete runtime JSON inputs include the original 1,534 contraction
inputs, 1,602 completed contraction output files, the accepted contraction receipt,
four complete original absolute numerator certificates, and the new source-AST
contract. Full rows and arrays are supplied. The 544 addresses, 34 fields, 17 full
factor proof sets, 20 native adapters, their source/grade/unit arguments and the
four original contraction identities are restored with their exact operands.
Structural equality is used for copies of the SAME operand, never as a replacement
for the opposite sides of an inherited cancellation proof.

`worker.py` supplies the new gate, containment, input/copy and append-only JSON
chain, runs the preamble, and then performs the numerical routes and comparisons.
`prepare.py` joins the exact constant quotients and their original reconstruction
proofs, epsilon/independent grades, source/test support and actual wave multiplier.
It selects the actual original X/Y interfaces from every accepted unit return,
requires the selector to be the integer zero, and joins fields, coefficients,
address membership, derivatives, centers and scales before saving the X/Y specs,
Y's negative argument/carrier, centers and units. New per-address identities
factor the native coefficient into normalized n=0 or n=2 families; the complete
native template and unit returns are inherited. `validation.py` supplies new
whole-definition/argument joins: original whole bytes and signatures map to the
RIGHT operands of completed inner arithmetic; physical original density arguments
map to its LEFT operands. The completed arithmetic zero is inherited without
rechecking its opposite sides. Each primitive then joins its actual original
contraction density. Every live original whole call is matched through the actual
permitted-call map to its native template, where J is selected with the separate
H tag set formally to zero, or D is selected once. This does not assert H vanishes.
The existing ordinary-component flag is required. The actual consumer with one
epsilon also joins its stripped coefficient by a new identity. All 20 eligible entries
must be pressure slots with N=1. Every one of the other 44 applicable entries
retains its inherited exact-zero reason. No unknown/nonconstant field qualifies.

The preamble executes NEW centered Gaussian derivative/moment polynomial joins,
new implemented-parameter joins on exact stand-ins, and source-AST outgoing-root
identity. It calls the new combination function on formal symbols and compares
it with the complete saved contraction formulas. This is a new implementation
join, not a rerun of old factorization. Original strip envelopes transport through
the same actual constant Fourier integrands and assessed Gaussian identity; no
new numerical envelope sample substitutes for that argument. The four original
nonnegative numerator certificates explicitly support a triangle majorant of
each added direct term. The old base tails are restored; only K29/T124 arguments
of the unchanged positive tail expressions are new. The original tail moment and weighted-tail function ASTs, and all four actual
positive contribution expressions, must match the new implementation. The
enlarged J tail retains the original positive H overcount as well. New identities
join the actual separate primitive numerator forms to the original certificate
operands; accepted polynomial-gap proofs are not rederived. Every address/primitive
tail must independently be below epsilon=1e-11/80, before the separate positive
grand-total check. Repeating the positive D bound for each primitive is recorded
as overcounting, never signed cancellation.

`geometry.py` uses the old generic exact quadratic-field arithmetic only, not its
old arrangement constructor. New plans split at all six affinity slabs before
intersecting all root, box, clip, profile, carrier and inner-grazing graphs. Both
outer packet/profile offset lists are explicit. The audit independently checks

Native geometry will run only inside containment; tooling tests use unrelated

`numeric.py` (the numerical library) restores the three immutable rule payloads.
A24 and A48 own independent 30-digit contexts and values, with open squared maps
on both halves of each interval. At every own outer node, each route obtains its
own inner GL24/48 pair; absolute differences are summed PANEL BY PANEL before
forming the contracted products. B50 restores physical-variable G7/K15 in an independent 50-digit context, with a global active-leaf vector sum.
The leaf selected for refinement has the largest contribution to the currently
worst normalized addressed component and its binding total-error or weighted-
nested guard. The same binding guard scores each active leaf. There is no local tolerance halving, new
rule construction, timed continuation, higher-order retry or precision fallback.
The root and profile source conventions are shared; numerical agreement does not
independently prove those conventions or endpoint smoothness.

Each new transform evaluates its own Gaussian formula: direct derivative identity
on A, centered moment recurrence on B. Private opposite-formula and 60-digit
comparison contexts preserve the exact represented momentum tuple. The native
coefficient is multiplied in EACH formula's own context before comparison. Full
values and Gaussian-stripped complex amplitudes are compared, and actual differences
and reconstruction residuals propagate. The B derivative mutant replaces Q by the
constant (i*p0)^n; it does not accidentally retain the original Q recurrence.
The normalized family carries the proven i^n in alpha exactly once.

Every addressed primitive has epsilon=1e-11/80. Product indicators use
|a| e_b + |b| e_a + e_a e_b, with positive weights/coefficients throughout.
B's pointwise inner target is epsilon*(1+1/|q(m)|)/(16*(3M+4)), and the ACTUAL
weighted inner total has its separate epsilon/4 guard. A's positive panel-pair
indicators have the same weighted guard. Original rule nodes remain unsampled at
endpoints; numerical alias or an unrepresentable midpoint is fatal. The indicators
are empirical, not rigorous forward error enclosures.

Comparisons cover every address/primitive, face/primitive, retained grade,
J subtotal, direct subtotal and J+D subtotal, independently for both carriers and
windows. A24/A48, A48/B50 and window enlargement use the unchanged
1e-9+1e-7*abs(A48) gate. The native wrong-reflected-root control uses address 8347
and its distinct clipped-input/unclipped-output formula. The derivative control
uses the smallest actual J n1=2 address, 8350. The wrong-root mutant emits only
its actual Dr label, with no duplicated Dh/Dq mutant subtotal. Both run through all three full routes,
both windows and carriers. Movement must exceed ten times the summed finite-window

`request-index.py` extends the unchanged lossless `evidence-store.py` writer. New
request namespaces include route, purpose, precision and full immutable mathematical

Every numerical panel input precedes evaluation. Per-node requests and formula
checks persist independently, and successful node-batch prefixes are committed on
a later callback failure. No batch exceeds 48 nodes; records exceeding 8 MiB refuse.
SQLite uses FULL transactions, a small fixed cache and file-backed temporary data.
The optional payload cache is disabled (zero bytes); completed returns remain on
disk. Disk admission reserves 20 GiB at launch and before record writes. Total work,
storage, process RSS and cache split remain unknown until actual execution. The
capacity refusal is a resource safeguard, not permission to retune or restart.
