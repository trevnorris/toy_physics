# Evidence navigation

The newly authored `method.md` changes only the proposed numerical treatment of
the constant-field J/direct subset of the two original Gaussian pairings.
`packet-action-method.md` preserves the original physical target and numerical
obligations, including those still pending for other components.
`contraction-method.md` is the original finite-window identity proposal, whose
subsequent exact operands/returns are supplied in `contraction/`. No old review
is included. There is no new numerical worker in this packet.

Start with `constant-subset-source-index.json`. This is a source/JSON-only index,
not a new symbolic or numerical certificate. It records actual saved selectors
and complete original addresses, constant fields and polynomial records for the
20 candidate entries, plus all 64 applicable statuses. The source files are
supplied in full; no field/grade array is omitted from its original file.
