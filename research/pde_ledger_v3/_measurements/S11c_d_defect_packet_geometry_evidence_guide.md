# Packet geometry build evidence guide

Start with build.md and review-prompt.md, then worker.py/library.py and inputs.json.
method.md is the new pressure-readiness method; packet-action-method.md is the
unchanged two-packet numerical prescription. This concrete build implements ONLY
the geometry/dependency/count subset. No pressure unit certificate is claimed.

- library.py: exact quadratic arithmetic, labelled affine arrangement, independent
  incidence/coverage audit, both-domain specifications and rule occurrence counts.
  Only synthetic Q(sqrt2) cases have run in tooling-tests.py; actual Q(kappa)
  plans wait for source assessment, gate, containment and runtime inspection.
- worker.py: gate/authority/argv checks; inert containment helper extraction;
  complete saved copies; native field/factor/adapter argument joins; family
  descriptors retaining544addresses and442zeros; new exact plans and controls;
  conditional counts and append-only chain/posthashes. It imports no CAS or
  numerical library. Symbolic JSON is never scientifically reconstructed.
- saved/selected/pressure-addresses.json contains all544entries with all keys.
  saved/inventory/THETA_BALANCE-ordered-addresses.json is the complete original
  2652-entry row. No subset of keys or matrix arrays has been supplied.
- saved/pressure/fields.json and saved/field/ provide all34complete field
  definitions, numerator/denominator vectors and original reconstruction
  operands/zero returns. No polynomial is recomputed; these data join addresses.
- saved/factors/ has17complete original full-factor and native-normal proof sets.
  The operandSha256 appearing in an address is NOT a file hash. The manifest and
  immutable copy receipts provide byte identity separately.
- saved/preflight/numeric-factor-adapters.json has20complete both-face/slot
  definitions and544address joins. The full numeric-factor-*-arguments/input/
  return files provide original address/call and mapped-template operands.
  Opposite sides of an inherited cancellation proof need not be structurally
  equal. New code may not simplify an old proof again.
- saved/preflight/physical-plan.json and checks.json pin the actual heldomega3,
  speed/carriers/centers/width and K27/U75/T122. saved/physical-input.json and
  local/context.json retain original material/frequency origin. The actual
  inventory/native-profile-scale-join.json supplies the L10 origin.
- saved/rules/ contains complete original24/48/7-15 rule records. Only metadata
  counts and precision are inspected here, without node/rule reconstruction.
- saved/accepted/ contains original bank/check/database receipts. Databases are
  not copied or opened; no old request is reused, no byte/RSS inference is made.
- source/preflight.py and source/inner-library.py provide the original adapter
  interface and evidence-layout context for read-only assessment. Neither is
  imported. Runtime-source/ contains the unchanged guard/supervisor/hook/helper
  and standing policy. launcher.py is hook-first; no READY gate exists yet.

All266runtime inputs are complete immutable files. The full pressure summand
unit sources are intentionally not repeated in this subset because no unit
computation or unit-readiness claim occurs. The manifest pins a local method
assessment record for future execution, but reviewer reports are not exported.
No peer reports, author CLEAR or previous reviewer commentary are supplied.
