# Complete source and saved-evidence guide

Start with worker.py::run and library.py::Walk/statements. These are the only
new scientific dimensional interpretation. Runtime-library source helpers are
inert constructor/metadata routines; no CAS/numerical library is imported.

source-contracts.json gives exact original line/column/text/hash locations in
original-source/*.py. In particular inspect generic inner kernel_components,
its actual numeric and exact-adapter callers, preflight parameter/templates,
reference A/originalPV/H contact, and native ordered raw profile scale.
Full original source files are supplied. These are inspected, never executed.

saved/source/result-record.json is the accepted previous unit-transport
inspection, not a new review report. The544complete address inputs/returns and
numeric binding arguments/results give actual original fields, grades, jets,
units and provenance. saved/native carries the original effective registry,
physical binding, lower geometry, profile scale and native Fourier contract.

saved/preflight has all20complete numeric adapter arguments/inputs/returns,
all544wave argument/return pairs and full adapter routing. saved/factors has
all17complete native factor proof sets. saved/inner has the complete generic
arithmetic/physical profile/PV/contact proof operands and exact returns.
Its saved unit flags remain historically false; this build supplies new units.

saved/reference and saved/raw-direct contain the original ordered transforms,
argument expansion, full retained native first-shape map and actual old zero
returns. saved/whole-origin contains all three complete H/J/D definitions;
saved/pressure contains their typed original tags. No whole is another density.

saved/fourier has the complete19family interface records and transform
convention. No190numerical samples, rules or large SQLite banks are reevaluated.
The full original Fourier product source is included for sign/normalization
and derivative-order inspection. saved/origins joins historical source hashes.

Tooling tests use manufactured expressions or read-only file/AST metadata.
They do not execute native unit walks or certify this scientific result.
The inherited gamma inference, accepted algebra and analytic Fourier/
distribution conventions remain explicit dependencies. Current evaluator
readiness and full action values are excluded.
