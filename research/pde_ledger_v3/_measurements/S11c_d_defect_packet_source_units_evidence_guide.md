# Packet navigation

The complete saved-input manifest is inputs.json; each savedInputs alias maps
to a complete file under saved/. No symbolic restoration or scientific tools
are authorized for this review. Constructor strings may be inspected as text.

1. worker.py run(): actual native unit roots, original bindings, six rational
   groups, source jet reconstruction, profile maps and complete address joins.
   library.py contains only the new strict identity/transport helpers and loads
   runtime-source/S11c_d_defect_packet_native_units_lib.py, the unchanged unit
   engine. launcher.py is only a future hook-first guarded launcher; no gate.
2. saved/native/: actual unit inputs/walks/returns, effective registry and four
   inherited consumer coefficient units. result-record.json is scientific
   completion metadata, not a reviewer report. Its scope leaves transport open.
3. saved/original/: complete old physical/binding context, raw source inputs,
   chemical normalization/domain, both source splits and native THETA input.
4. saved/composition/: complete source joins, denominator component certificates,
   all six rational splits/remainders and exact return pairs, eight full source
   jet tables/reconstructions, consumer epsilon identities and 392 profile maps.
   profile candidates are locators only; the worker must join actual input too.
5. saved/inventory/: all544selected addresses and complete coefficient-transform
   records. saved/fields/: all34full polynomial/numerator/denominator/coefficient
   records and reconstruction input/returns. No isolated coefficient lists.
6. saved/source-contracts.json and source/ contain the original complete
   producer source interfaces, read-only. No source function is re-executed.
7. tooling-tests.py uses synthetic operands only. Test success does not establish
   an actual native unit or future worker acceptance. No reviewed peer report
   is present. The native result metadata retains historical record references.
