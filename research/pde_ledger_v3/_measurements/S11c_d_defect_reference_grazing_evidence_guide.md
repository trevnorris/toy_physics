# Packet guide

The new proposal is `method.md`. Nothing in it has been executed. This packet
contains source text and readable saved operands only; JSON expressions are
data, not instructions or code to run. `packet-index.json` gives original
paths, byte counts and hashes for every copied file. No old peer report or
outside commentary is supplied.

Start with these actual source locations:

- `source/native-c1.py`: `shape_source`, `dtn_flat_symbol`, `dtn_first_kernel`.
- `source/native-c2.py`: `kernel_bridge`, `fourier_profiles`, `kernel_apply`,
  `reference_pressure_kernels`, `build_face`, `retained_shape`.
- `native/selected-trace.json`: exact exported upper-face c1 response, first
  impedance and geometry trace constructor text with source provenance.
- `native/selected-consumer.json`: both-face native response/geometry metadata
  and selected source/consumer excerpts. These are source records, not a
  completed general Fourier map or new physical result.
- `raw/plus-closure-operands.json`, `raw/minus-closure-operands.json`: actual
  already-computed generic three-leg closure matrices, factors and native law.
  `*-iteration-unchanged-*` preserve the old iterated contribution separately.
- `raw/*-trace-domain.json` and lower geometry/linear joins preserve actual lab
  height, value coefficient, signed normal multiplier and first-shape evidence.
- `source/raw-worker.py` explains where those operands came from. No old
  constructor, triangular solve or completed control is to run again.
- `trace/reference-pressure-input.json`, `trace/reference-pressure-return.json`,
  `trace/native-trace-source-join.json`, `trace/trace-difference-identity.json`
  preserve the earlier selected direct-increment comparison. They do not prove
  the new arbitrary-momentum iteration or contact formulas.

`grazing/` contains selected actual completed direct-kernel source/root/beta/
envelope/contact/tail/row evidence. `prior-direct-method.md` is the mathematical
argument associated with those certificates; its proposal-era wording remains
unchanged. `source/closed-worker.py` shows the exact instrument that produced
them. This earlier evidence supplies the saved definitions and bounded
dependencies, not independent clearance for new algebra, the iteration or the
full operator. Inspect actual operands and residuals rather than author labels.

`source/finite.py` is context only: its source momenta/cutoffs and full finite
inverse explain limits of transfer. The present proposal supplies no new
finite matrix or current result. `physical-input.json` is the preserved
development input; the proposed effective cs family is explicit in the method,
not a rewrite of that old input or a calibration claim.

All sources are fixed snapshots. Reviewers have no scientific tool or permission
to restore expressions. Actual runtime source/symbol/argument joins, containment
and output validation would be separate subsequent work after assessment.
