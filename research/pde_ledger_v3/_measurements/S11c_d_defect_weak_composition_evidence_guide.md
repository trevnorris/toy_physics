# Fixed packet guide

`method.md` is the NEW unexecuted analytic proposal. Nothing in its new global
bounds or weak-space conclusion is an accepted numerical or symbolic result.
`packet-index.json` records hashes, complete-file copies and explicit JSON
selection paths. No peer review, old verdict or outside commentary is included.

`inventory/fields.json` contains all 34 actual coefficient fields. The method
requires a new all-field polynomial/derivative certificate; prior selected
nonconstancy controls do not establish it. `inventory/address-representatives.json`
contains complete saved records grouped by actual face/slot/grades, source and
consumer coefficient IDs, response component and wave jet. The metadata summary
retains zero/nonzero-status counts and original file hashes; selection does not
assert that a formal nonzero-looking contribution is a nonzero field value.
`inventory/grade-coverage.json` is the complete 320-entry ordered grade census.

`inventory/` also contains actual native source stages, full rational grade
splits, pre-binding speed inventory, L=10 native profile-scale join, typed direct
objects, whole-tag signatures, complete argument maps, raw/full response-factor
joins and selected controls. These are completed operands and literal returns.
They are not independent physics revalidation. No completed function may be
replayed. `source/composition-worker.py` shows their provenance and actual
Fourier/address definitions; `source/native-c2.py` is the untouched native route.

`saved/` preserves the preceding instrument's 122 original input files, including
native source excerpts and both faces' source/consumer, raw/direct and reference
operands. Start with saved/reference/retained-response-census.json, its separate
left/right mixed assignments and trace subtraction, and saved/direct/closed-density.json.
The original c2 iteration and independent direct augmentation are distinct.
Flat support identifies q(k) with q(l) only on its diagonal; off-diagonal
four-depth maps remain independent. Dwhole is an already closed whole object.

`bounds/direct/` supplies the completed compact-domain root/beta/envelope/contact
certificates, and `bounds/reference/` supplies the completed remaining bound,
collision and distribution-limit objects. `prior-direct-method.md` and
`prior-reference-method.md` supply their analytic arguments with original scope.
They do not certify the NEW all-momentum bounds. In particular, the old numerical
upper bound |q|<=5 and tail estimates using |k|,|l|<=3 must not be extrapolated.

The physical input remains the old development file. This proposal uses its
same real-frequency material/source binding and effective cs=[1,2] only in the
response law. It is not primitive calibration or a flowing medium. Unit joins
are inherited/required; no fresh full dimensional proof is supplied.

Scientific imports/restoration or new probes are not part of this review.
If cleared, actual source/symbol/argument joins and new certificate checks would
run later under the existing no-deadline pooled guard and be inspected separately.
