# Concrete translated weak-end build evidence

Start with worker.py and method.md. This fixed packet supplies every consumed
runtime saved file (all422 aliases, no array omissions), the original source,
and concise projections for navigation. No scientific execution is permitted
in review. Absolute repository/scratch paths in files are provenance only; read
the copies under input/. saved-input-map.json maps aliases and file hashes.

The full address arrays are deliberately available, but contain many repeated
zeros. Use address-review-index.jsonl for the complete route metadata, then
address-representatives.json for complete records of every distinct response
factor/face/slot/grade/status/source-jet shape. Full arrays are at
saved-inputs/inventory/<row>-ordered-addresses.json. All400localcells are in
saved-inputs/full/all-local-cells.json, including original operands, published
zero returns, endpoint values and source child indices. Tests inspect their
metadata without restoring scientific objects. State actual review coverage;
do not claim you independently recalculated these saved results.

## Worker flow and joins

- verify_gate/verify_build_assessment/verify_invocation require a fresh exact
  paired build record, matching method/helper/authority/worker/manifest/launcher
  and command paths. No gate is shipped because assessment is still pending.
- main verifies before output/import, then native containment before SymPy.
  Generic Journal/decode/containment definitions come from inert-helpers.py;
  no old scientific run body is imported or called.
- run_science copies saved files byte for byte and checks published full-weak
  artifact receipts. Source/local pressure physical contexts share the original
  input; only existing frequency/effective-speed conventions apply.
- local coefficient and endpoint values are reused. The physical-tanh identity
  and formal-T identity are different saved arguments. Pressure polynomial
  files store a numerator and denominator separately; certificates/P0 store
  the complete quotient. New endpoint evaluation uses the complete polynomial,
  joined to the actual old reconstruction argument and literal zero return.
- The restricted native_phase_exponent interpreter accepts only the actual
  exp/arithmetic/sum(zip()) grammar. It binds both native source and profile
  exponent strings to the new coordinates and momenta, derives the common
  translation increment and checks their sign relation. A flipped profile sign
  moves that actual relation. No eval/exec, old function or producer is called.
- New exact translation/PV algebra persists the oscillatory diagonal term.
  Functional-analytic steps are the reviewed arguments in method.md, inherited
  whole-kernel continuity/envelopes and both native Holder certificates. They
  are not encoded as machine measure-theory proofs or sampled numerically.
- Both-face native constant-height work uses the original saved first-shape
  operand, height maps, trace signs and final affine slot. The saved first-shape
  operand is split into its independent height (10) and slope (01) grades,
  with full exact reconstruction and grade-free coefficients required. Both
  operands are preserved before these checks. The common-depth zero assertion
  applies only to the height grade; sigma remains live, and the diagonal slope
  operand is saved without a pointwise-zero assertion. Its translated weak zero
  follows from the separate inherited ordinary-kernel argument, never j(0)=0. The original native
  c2 assignments are checked by AST; no constructor, triangular solve or old
  trace function executes. New symbols are real3; auxiliary delta remains proof
  context only.
- Each pressure address joins its source/consumer fields, grades, wave multiplier,
  full factor/normal map and completed proof. Flat support reduces all momenta
  only after the delta; height uses contact/Dirichlet. Ordinary slope/mixed blocks
  are tagged with their analytic weak-zero reason, not evaluated or dropped
  earlier. Source/consumer cross grades stay in the new end sums.
- The output comprises200scalar end-symbol cells (2ends*5rows*5fields*4grades),
  no finite system matrix or inversion. Normalization is the coefficient of one
  epsilon_shape; exact zeros have no epsilon power. Full Fourier pairing is2pi.
- Control eligibility is drawn from all actual addressed grade/face/slot/status
  records. Height-contact and reversed-phase mutations use height-response
  addresses. The lower native sign mutation uses a surviving FLAT normal-slot
  address, whose consumer can have grade10. No excluded grade20 is added.
  The reversed exponent is derived from the actual native phase; its Dirichlet
  limits plus the surviving contact must exchange BOTH heights, and the mutated
  terms enter both actual end cells. Actual finite nonzero endpoint movement is
  mandatory at runtime; metadata eligibility alone cannot establish it.
  The declared point
  p=1,q=2 has cs^2=180/101 in[1,4] and positive outgoing depth. Nonzero movement
  must be certified exactly; absence of an applicable control is fatal.
- EvidenceLog fsyncs inputs/returns before guards. Partial row address returns,
  exceptions, original copies and source posthashes survive failure. Exit0 is
  not acceptance; the later completion audit remains required.
