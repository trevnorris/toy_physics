# S11c-d bounded source Fourier factorization

The accepted quadrature-domain check derives a momentum width a/10 and
demonstrates that panels around this width resolve the elementary Abel mass.
Ordinary tensor-grid enlargement is inefficient. Before applying these panels
to the complete action, separate its source-position integration so large
momentum/source tensors need not be materialized together.

1. Consume all 80 original nonlocal integral operators from the accepted exact
   assembly. Retain their complete symbolic coefficients and both five-field
   source-row joins. Introduce explicit positive finite cutoffs for every
   existing integration variable, including nested profile transforms.
2. Factor each actual bounded integrand into a sum of source-position factors
   times coefficients independent of that position. Split only computed
   exponential phases and preserve all Piecewise branches, momentum roles,
   profile functions, derivatives and measures. Record literal phase and
   integrand reconstruction residuals against the original operand.
3. Derive the source-frequency character and source amplitude of every factor.
   Retain the original phase, its logarithmic derivative, normalization at
   zero source position and amplitude-reconstruction residuals. Do not assign
   an input momentum by name; obtain its argument from the actual phase.
4. Construct bounded source Fourier integrals from those factors and retain
   the remaining momentum integrals. Any interchange applies only to finite
   domains at positive regulator with the stated smooth test/profile and
   nonsingular-denominator conditions. It is not an identity for the original
   infinite-domain distributional action and does not take the Abel limit.
5. Validate all source, operand, dimension/grade and emission joins and publish
   the factorization checkpoint. Then bind the already approved test fields,
   evaluate/refine the source Fourier factors, and apply concentration-aware
   momentum panels with explicit memory bounds. Compare complete actions
   before advancing physical domain/tail/regulator limits or boundary matching.

Preserve the native reduction and previous numerical implementations. Reuse
the accepted caches, one CAS job at a time, with durable repository scratch
storage and a silent completion/error watcher. Publish .out through DataLad/
git-annex, verify hashes and commit each step. No upstream physical change is
authorized by this numerical assembly plan.
