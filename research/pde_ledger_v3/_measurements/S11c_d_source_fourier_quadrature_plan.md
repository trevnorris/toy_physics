The bounded factorization is accepted at bed088be. Its 80 native integral
operands, 35 distinct source integrals and exact reconstruction certificates
are retained. This step binds those operands to both previously accepted
Gaussian test fields and the approved material/profile input. It does not
reconstruct the reduced action or the hour-long factorization.

1. Verify the published factorization, certificate and per-row hashes, its
   accepted source snapshots and the unchanged native engine AST. Verify the
   numerical-action test packets, complete input projection, source action
   and exact assembly joins. Preserve the symbolic source integrals and units.
2. Bind each actual source amplitude, character and frequency. Derive each
   frequency range from its affine dependence on the three normal momenta
   and the recorded finite momentum box. Check every factor's source identity,
   test-field assignment and original limit/remaining-momentum order. Compare
   each actual assembly field/row/term occurrence with its saved test operand;
   retain literal pairs and raw residuals. For unequal representations use the
   existing exact rational/phase certificate helper, requiring every normalized
   and proof residual to vanish while the original limit tuples agree exactly.
   Check a one-sided coefficient mutation and a changed-limit control. Retain
   all original singular-domain restrictions; this is a finite smooth test.
3. Evaluate every distinct source integral for both tests. Use panelled Gauss
   rules at three orders, bounded frequency batches, and independent adaptive
   real/imaginary integration over the same source interval. Include zero,
   extrema, interior frequencies and the test carrier when in range. Compare
   the original bound source with the separated amplitude/character at actual
   momentum assignments. Record a change in the original integration weight
   as a sensitivity control. Save binding comparisons per test and each bound
   source record before later guards; then save every completed integral.
4. Repeat on a larger finite source interval and retain the resulting changes
   separately from quadrature errors. Report adaptive error estimates and
   the conservative phase-workspace estimate and process peak RSS. Numerical samples and finite interval
   differences do not certify a uniform interpolation error, infinite source
   tail or operator/Abel limit.
5. Replay all emitted values, dimensions, grades and write-keys. Check packet
   and source hashes before/after emission, publish the accepted transcript
   through DataLad/git-annex, verify hashes and commit. Then use these reusable
   source quadrature operands to implement the complete concentration-aware
   momentum integration, preserving all three Abel transfer pairs and nested
   profile factors. Resolve fixed-regulator full-action quadrature before
   action-domain/tail/Abel limits or two-ended boundary matching.

Keep the original Fourier reduction and symbolic coefficients intact. No
upstream repair or physical input change is proposed. Durable runs stay in
repository _scratch/s11c/ with one CAS job and a silent completion/error
watcher. Preserve every completed packet on failure; resume only with exact
source/provenance joins or an explicit instrument-repair join. Preserve the
builder report's retained solver/export contract suffix.
