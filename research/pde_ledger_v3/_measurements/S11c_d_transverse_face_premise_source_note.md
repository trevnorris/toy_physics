# Transverse/face premise worker: source schema and limits

This is an unexecuted instrument for independent build review. Preparation
approval cannot launch it: a later pinned user science approval after the
costed-plan stop, a fresh build gate, and ordinary guard/supervisor containment
are required. No scientific payload was restored to write this worker.

The saved pairing schema is `(packet, knownDimensions)` with
`packet['result']`, as saved by `S11c_d_end_pairing_check.py:165-166`.
Frequency packets supply `originalAlgebraic`, `originalRelation`, `radical`
and saved branch joins. The original live symbols are rebound, rather than
promoting the compact fixed-tangential pencil. Endpoints are replaced using
`uniform['profileEndpoints']`; no profile limit is evaluated.

The two-column lift comes from the accepted curl matrix. A 2×2 geometric Gram
inverse restricts the physical 5×5 pencil; full-pencil invariance, source joins,
Hermiticity, live frequency/tangential dependence and actual loss-side face and
current contractions must support the restricted question. No H roots,
resultants, discriminants, strong-pencil inverse, LU, producer or response is
constructed. Zero-ray chart degeneracy remains unresolved.

REFERENCE is attempted first; LEFT and RIGHT retain separate evidence. Each
supported end saves a short fixed-ray prefix before optional generic loci.
Only zero-normal T candidate equations and the acoustic bulk-availability
boundary are attempted. Candidate slices receive actual both-side samples;
these do not certify a plane partition. A finite grid retains explicit
available/absent/unresolved states and incomplete coverage. Source/chart
exclusions use the quadratic depth relation and exact univariate interval
certificates; unsupported cases remain unresolved. Physical damping is retained.

Selected saved modes 16/17 are used only as source-comparison operands. Their
stored sheet/current eligibility, actual T membership, pencil, physical depth,
current operands and loaded source controls are checked, without rerunning a
root or nullspace producer. Their indices alone do not identify T modes. They
are a selected subset, not a complete seed census; the finite-response current
summary is not substituted for this comparison.

The c2 readable index supplies velocity identities only. Their hashes and face
addresses are joined to the source's native face order (read using Python AST).
The d pairing additionally supplies flat-face pressure/velocity scales and
native rows for their reconstruction joins. This is **not** a c2 first-shape
pressure, trace or normal-jet check. Those maps and `C1 Psi0` remain downstream
work. The native eW omission, native drive-term omissions, dependent physical
slot probes and loaded frequency/tangential source omissions retain operands
and actual movements; silent controls yield unresolved claims.

Journal input-reference files point to complete content-addressed pickle
objects. Strong identity references prevent stale-id aliasing. Each operation
has its own receipt even for identical outputs. Every completed return remains
saved; operation-budget exceptions derive from `BaseException`, preserve the
unfinished input receipt and cannot be swallowed by ordinary algebra handlers.
There is no retry. A whole-job timeout preserves the planned grid, completed
point files, active operation, posthashes and failure record.

No physical-light calibration, full matched-end/retained-grade localization,
first-order outgoing field, loss coefficient, exterior power split, full
Green/FORM, A11/A12 or radiating witness follows from this instrument. Runtime
cost is unmeasured. Preparation checks were standard-library source/JSON/hash
reads and AST parsing only; no CAS or numerical test was run.
