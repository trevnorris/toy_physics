## G-1 · The class system is defeated by a typo, silently

**Measured.** `extract_knob_inventory.py` builds its set of declaration sites from *lines that already
match the annotation pattern*. So a malformed or out-of-set tag does not read as an **untagged
declaration** — it reads as **not a declaration**, and the object falls through to the default class.

Mangling the separator in the posited action's annotation moves `lagrangian` from `PREMISE` back to
`DERIVED` while the engine `.out` stays **byte-identical**, the engine exits **0**, and the extractor
reports **`FINDINGS: none`**. The identical mutation on an `sp.Symbol` line *is* caught, which is the
contrast that proves the gap.

⚠ This is the recurring shape in this project: **acceptance decided by whether a source line matches a
pattern is dodgeable by not matching it.** A finding must be raised by the *absence* of a valid tag on
something that structurally is a declaration.

**Fix.** Enumerate declaration sites **structurally** — every module-level assignment — and report as a
finding any that carries no valid tag, or a tag outside the closed set, or a malformed annotation. The
mutation above must produce a finding and a non-zero exit.

**And the class must reach an artifact.** The engine currently emits **no class information at all** into
its `.out`, so the class tally lives only in a builder's transcript and **no output diff can ever show
class drift.** Emit the classification as a computed object like everything else. ⛔ Not a typed sentence —
the tally read out of the collection that was actually exported.

## G-2 · 134 of 139 classes hang off one comment on a dict accumulator

**Measured.** The default class is read from the annotation on `all_outputs = {}` — a Python accumulator,
not a physics object. **Flipping that one comment moves 134 class fields.** Mangling it is a hard
`KeyError`. F-4 asked for one source of class truth; what exists is one source for 5 entries and one
unowned default for 134.

**And two exported entries are posited, not derived:**

- `energy_density_dimension` — the right-hand side of the entire dimension linear system, hand-typed.
  Perturbing it moves the exported `rho_br` and `mu_R` dimensions.
- `squared_velocity_dimension` — hand-typed, and it is **the reference `SPEED_DIMENSION_DIFFERENCE` is
  measured against.** Exporting it as `DERIVED` records a check's own expected value as a derived result.

**Fix.** Annotate both `PREMISE`, so their class comes from their own declaration like everything else.
Then deal with the default: a class must come from the object's own annotation. If a default is
unavoidable for objects with no declaration site of their own, it may **not** ride on an unrelated
variable's comment — make it explicit and name it in the report, and say exactly which entries take it and
why they have no annotation of their own.

⚠ Then re-ask the question the legs asked: **is anything else among the `DERIVED` entries posited rather
than derived?** Two were found by reading. Look for hand-typed reference values, chosen forms, and
anything a control would move. Report what you find; do not guess.

## G-3 · The agreement count excludes the wrong rows — exclude for ENTAILMENT, never for reading zero

⚠ **My round-1 instruction was wrong and this supersedes it.**

**Measured.**

- `DYNAMICAL_MATRIX_ROUTE_RESIDUAL` is guarded to zero in-engine ⇒ genuinely uninformative ⇒ correctly
  excluded.
- `SPEED_DIMENSION_DIFFERENCE` is **not guarded**, and it is **the only row that would catch the two
  engines typing different velocity-squared references.** I had it excluded. It is the informative one.
- `COEFFICIENT_DIMENSION_DIFFERENCE` is literally *stiffness minus inertia* in **both** engines, and
  `IMPLIED_SPEED_DIMENSION` reduces to the same difference for the main package. ⇒ once rows 6 and 7 agree,
  **neither can disagree.** Both were counted.

**Fix.** Restore `SPEED_DIMENSION_DIFFERENCE` to the count. Exclude `COEFFICIENT_DIMENSION_DIFFERENCE` and
`IMPLIED_SPEED_DIMENSION` **as entailed by rows 6 and 7**, naming the entailment. Keep emitting all of
them — they are honest outputs — but the **count of independent cross-engine agreements must count only
rows that could have disagreed.** Report the number and the exclusion reason per row.

⭐ The general rule, and apply it to every row rather than only the ones named here: **a row is excluded for
being entailed by other rows, never for reading zero.**
