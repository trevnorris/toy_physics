## What must be true after the fix

1. **Objects unchanged.** Every locus-protocol record remains exactly the object
   `directives/S11_SHARED_PHYSICS.md` §5 names — all five core and four extension objects, the
   pinned payload field sequences, the pinned token vocabularies. The fix changes computation
   routes only. `_IDENTICALLY_SATISFIED` and `_INCONSISTENT` remain computed from `_EQUATIONS`
   (spec line 251 binds: never read off any solver's return, including this cell's own
   `_SOLUTION`).
2. **Every `TEST_OBJECT` stays a live computed boolean.** No token or payload may survive a form
   perturbation of the action unchanged where the spec ties it to the action.
3. **Honest incompleteness stays available.** Where a bounded route cannot decide, the record
   carries the spec's undecided/not-applicable token with the live operands of the failed attempt.
   No route may be retried-until-green against a visible target, and no token is ever chosen to
   make a cell complete.
4. **XKIN_ANISO D3 and D4 run to cell completion** under the per-cell contract
   (`wolframscript -file <wl> XKIN_ANISO <D>`, fresh kernel), each within a 7,200 s wall budget,
   with no silent gap: any single stage exceeding budget must fail loudly naming the stage.
   **D2 is attempted under the same contract with the memory guard armed**; a guarded death is a
   measurement to report, not a build failure — and not a license to skip the attempt.
5. **The 19 completed cells are the regression bar, run for real.** Re-run every completed cell
   with the fixed engine and compare physics tags (`WL_S11_*` minus `LOCAL_`/`RUN_`/`TAG_NAMES`
   bookkeeping) against the committed `.out` at `e2928b49`: byte-identical. Reading the committed
   file runs no engine; the comparison operand is a fresh run's output.
6. **Newly completing cells face existence + completeness bars**, never per-branch soundness
   alone: every locus the spec obliges for the cell emits all nine protocol objects
   (census by tag pattern over the full emission surface, not a sampled list), run-level tags
   emit, and emitted objects are spot-verified by exact rational specialization against their own
   `_EQUATIONS` — an oracle independent of the route that produced them.
7. **The measurements twin is generated by script**, never transcribed, and every measured claim
   in the build report carries its command and literal output.

## Builder operational constraints

- One kernel at a time (two-seat licence; nothing else running). Absolute paths everywhere.
  Transcript outside the repository. Never run the full sweep in one kernel — per-cell only.
- Long runs must show observable progress; long + silent is the failure mode under repair.
- The working tree is committed at `e2928b49` before the build touches it.
