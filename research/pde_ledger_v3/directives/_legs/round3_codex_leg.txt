## Blocking findings

### 1. `F8a` does not measure universality

The committed form ablations were selected from their actions: only `XFORM_FULLGRAD` and `XFORM_DIVONLY` genuinely change stiffness form. The measured partition is incomplete:

```text
D3_MAIN_OBJECTS=304
D3_UNIVERSAL_UNDER_FORM_ABLATION_COUNT=104
D3_ACTION_DEPENDENT_UNDER_FORM_ABLATION_COUNT=116
D3_UNDECIDABLE_MISSING_COUNTERPART_COUNT=84
D4_UNIVERSAL_UNDER_FORM_ABLATION_COUNT=102
D4_ACTION_DEPENDENT_UNDER_FORM_ABLATION_COUNT=109
D4_UNDECIDABLE_MISSING_COUNTERPART_COUNT=84
```

A concrete false universal is already in the committed run:

```text
D3_FALSE_UNIVERSAL_MAIN='(rho_br, rho_br, rho_br)'
D3_FALSE_UNIVERSAL_XFORM_FULLGRAD='(rho_br, rho_br, rho_br)'
D3_FALSE_UNIVERSAL_XFORM_DIVONLY='(rho_br, rho_br, rho_br)'
D3_FALSE_UNIVERSAL_XFORM_ANISO='(rho_br*s_rho, rho_br, rho_br)'
```

`Q6_INERTIAL_COEFFICIENTS` is invariant under the chosen `W` mutations but moves when `T` changes. If given a bare key, a future anisotropic action collides unnecessarily. For this example, `P4/F2` would probably reject the differing value, so the immediate result is a false loud collision rather than a silent overwrite. If the payload happens to agree, however, `P4` has no semantic evidence that the objects differ.

A false action-dependent classification can also be manufactured without changing the action:

```text
FALSE_ACTION_DEPENDENT_CONSTRUCTION='root-index renumbering; action unchanged'
FALSE_ACTION_DEPENDENT_CHANGED_SLOT_COUNT=104
FALSE_ACTION_DEPENDENT_UNORDERED_PAYLOAD_MULTISET_PRESERVED=True
FINITE_DATA_DECIDES_UNIVERSALITY=False
```

The mechanism is presentation/root-order movement, not action dependence. Nothing in `F8a` requires alignment before measuring movement.

What must become true: dependency scope must identify every physical input on which the named object depends; finite equality under two available mutations cannot be promoted to “universal.” Missing counterparts and generated symbol rows need an explicit undecided classification, not a guessed partition.

Evidence: [script](/tmp/s11_f8_partition.py), [literal stdout](/tmp/s11_f8_partition.stdout.txt).

### 2. Equal slug and descriptor can still name different objects

The S11 spec makes some objects depend on the declared additive-term inventory even when a declared density evaluates to the zero form. Then the simplified live `(T,W)` is identical, but `COEFFICIENT_ORDERING` is not:

```text
LIVE_ACTIONS_STRUCTURALLY_EQUAL=True
SLUGS_EQUAL=True
DESCRIPTORS_EQUAL=True
MAIN_DECLARED_COEFFICIENT_ORDERING=('bulk', 'mu', 'rho')
EXTRA_DECLARED_COEFFICIENT_ORDERING=('beta', 'bulk', 'mu', 'rho')
COEFFICIENT_ORDERING_OBJECTS_EQUAL=False
DECLARED_ZERO_TERM_RECOVERABLE_FROM_SIMPLIFIED_LIVE_ACTION=False
```

Thus the required descriptor cannot be recovered from the simplified live action without retaining declaration history. If declaration history is included instead, the descriptor no longer names only the mathematical action: two equal functionals represented by different declarations get different descriptors, preventing a meeting that should occur.

`F8c` also never defines the canonicalization or slug derivation, so the required descriptor is not uniquely computable as written.

What must become true: the identity context must cover declaration-sensitive inputs without pretending they are properties of `(T,W)`, and equal mathematical objects must still receive the same storage key.

Evidence: [script](/tmp/s11_f8_descriptor_cases.py), [literal stdout](/tmp/s11_f8_descriptor_cases.stdout.txt).

### 3. `F8d` violates Rule 6 more broadly than its stated `W`-only cost

Different full action descriptors can produce the same requested object:

```text
ACTION_DESCRIPTORS_EQUAL=False
ROOT_A=k2*mu/rho
ROOT_B=k2*mu/rho
ROOT_RESIDUAL=0
```

Here a common nonzero scale changes both `T` and `W`, while the generalized root is unchanged. Full-pair scoping prevents the cross-step root collision that should happen.

The lost comparisons are not limited to `W`-only objects:

- `T`-only: `KINETIC_TERMS`.
- `W`-only: `STIFFNESS_TERMS`, `Q7_W_FULL`, `Q7_CURL_TERM`.
- Action-independent: `Q7_CURL_DENSITY`, `Q7_CURL_REFERENCE`, `Q7_RESIDUAL`, `PD_TERM`, the complete Q9 census, and `C2_UNKNOWNS`/`C2_COUNT`.
- Scale-invariant action-derived objects: roots, multiplicities, orderings, signs, ranks, nullities, scaling exponents, and many locus/count objects.

The simplest literal `T`-only example is:

```text
FULL_ACTION_DESCRIPTORS_EQUAL=False
KINETIC_TERMS_EQUAL=True
```

What must become true: a key must not vary with irrelevant parts of the action, including common overall scale. `F8d`’s blanket full-pair scope must not suppress genuine comparisons.

### 5. `P1` does not decide the symbol population

Current data happens to contain no same-name assumption variants, but the admitted SymPy population permits them:

```text
TRAVERSED_SYMBOLS=("Symbol('x', positive=True)", "Symbol('x', real=True)")
TRAVERSED_SYMBOL_COUNT=2
AVAILABLE_FLAT_SYMBOL_KEYS=('x',)
ONE_ROW_PER_REFERENCED_SYMBOL_POSSIBLE=False
```

It also does not decide whether “referenced” means all symbol atoms or free symbols:

```text
ATOMS_SYMBOL=('x',)
FREE_SYMBOLS=()
P1_TRAVERSAL_POPULATION_RULE_SPECIFIED=False
```

Nor does it say whether F3 evidence fields participate:

```text
VALUE_SYMBOLS=()
F3_OPERAND_SYMBOLS=(evidence_only,)
P1_EXPLICITLY_INCLUDES_EVIDENCE_FIELDS=False
```

A builder must therefore choose the population and same-name collision behavior. A symbol needed only by evidence can be absent while `P7` still sees equality between its self-manufactured eligible and written sets.

What must become true: the traversed fields, bound/free-symbol rule, and same-name/different-assumption behavior must be decidable before construction.

A union interpretation gives new rows fields for which no truthful value rule exists; a per-row interpretation gives no shape to choose for a new S11 row. On the first added field:

NEW_ROW_FIELDS_WITH_NO_VALUE_RULE=('corroborated_steps', 'new_required_provenance')

What must become true: mandatory, optional, and F3 evidence fields—and compatibility behavior—must be unambiguous. Merely observing field names is not a schema.

## Rule 2, Rule 3, Rule 6, and process-cost audit

- Rule 2: `P5` is correctly three-legged, and `P7` is three-legged in one direction. `P4` emits test results rather than unconditionally requiring both reconstructed operands; `P8` does not state a guard; `F8c`’s slug/descriptor cross-checks and rename controls do not require both claims plus a residual before failure.

- Rule 3: `F8a` specifies the mutation recipe instead of the dependency object. `P2`, `P4`, `P5`, `P7`, and `P8` likewise prescribe concrete algorithms. For `F8a` and `P4`, that manufactures physics errors directly. The others are process machinery; they earn their cost only where they protect physics-bearing rows.

- Rule 6: `F8d` deliberately prevents valid meetings for `T`-only, action-independent, and scale-invariant objects. `P4` under the conjunctive reading prevents algebraically equal but structurally different reconstructions from meeting.

- Process-only cost: the English-description portion of `P10` catches no wrong physics. `F8` control 5 is a guard-for-a-guard; the successful six-control defeat shows it can be satisfied without validating the frozen map’s semantics. These fail the stated “less machinery” goal.
