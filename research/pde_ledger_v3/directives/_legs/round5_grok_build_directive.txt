## BLOCKING

### B1 — Four **shared** suffixes are fixed only in this directive; the Wolfram builder never sees them

**What is wrong**  
Shared leaves four Q1/Q2 emit targets **unnamed** as tag suffixes:

| Object the shared requires | Shared spelling | This directive pins |
|---|---|---|
| Expanded `L` | prose only (“Emit `L` expanded”) | `LAGRANGIAN` |
| Full EL system | prose only | `EULER_LAGRANGE_SYSTEM` |
| `M_A − M_B` | prose only | `M_RESIDUAL` |
| `M_A[[1,1]]/M_B[[1,1]]` | prose only | `M_RATIO` |

Shared **does** name `M_A`, `M_B`, `KINETIC_TERMS`, `STIFFNESS_TERMS`, route tags, etc. These four are the residual unnamed shared objects.

They are **shared** tags (not `_LOCAL_`). §8 parity obliges identical suffixes after stripping `PY_`/`WL_`. This file is the only place those four spellings appear.

**Mechanism by which a wrong result survives**  
Wolfram is built from a **different** directive and never reads this one. If it chooses any other spelling (from shared prose alone), the comparator reports **eight missing-tag rows** for four identical physics objects. There is no paired residual on those rows, so a reader cannot tell **vocabulary gap** from **absent computation** — the expensive failure mode.

**Precedent**

The **partial** vocabulary failure on exactly these four **is** still open.

2. **Both** engine directives pin the **identical** four spellings,

and the pin is **not** left only in the SymPy directive.

**Fix level:** shared specification (primary), or coordinated SymPy **and** Wolfram directives. ⛔ Not fixable by editing only this file’s intent while leaving Wolfram free.

### B2 — “Emit no additional shared tags” is **stricter than** shared §8:1084

**What is wrong**  
Shared §8:1084: if you emit an object with no supplied tag name, **choose one and list it in §10**.  
Directive: pin the four above, then **“Emit no additional shared tags.”**

That freezes shared vocabulary to  
`(shared-named) ∪ {LAGRANGIAN, EULER_LAGRANGE_SYSTEM, M_RESIDUAL, M_RATIO}`  
and forbids §8:1084 for anything else.

**Mechanism**  
If Wolfram (legally under shared) invents a fifth shared name under §10, SymPy is **forbidden** to match → another vocabulary gap that looks like missing physics. Conversely, if SymPy needs a fifth shared name, the directive pushes toward **omission** or incorrect `LOCAL_` placement — silent absence.

**Literal output**


**What must become true**  
Directive must not undercut §8:1084, **or** shared must name every shared object so no §10 naming remains. Fix level: **this directive** (relax to shared §8:1084) **and/or shared** (close the name set). Coordinated with B1.
