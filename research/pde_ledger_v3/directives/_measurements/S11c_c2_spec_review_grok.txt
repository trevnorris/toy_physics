## 1. Non-commutation — close-first is sound

**Verdict:** `extract(close(SLAB)) ≠ close(extract(SLAB))` for an operator of this shape, and **`extract(close(·))` is the correct object.** Extract-first is correct only when the closure does not mix sectors; that is not this problem.

```
R_x_open = A_TT x + B_Tth y + p
R_y_open = B_thT x + A_thth y + q
p_closed = α y + β x
q_closed = γ x + δ y
extract(open)        = {x←y: B_Tth, y←x: B_thT}
close(extract)       = {x←y: B_Tth, y←x: B_thT}
```

The spec counterexample reproduces: `extract(close)−close(extract) = α`. Same-sector closure (`p=βx`, `q=δy`) **does** commute (residuals 0).
