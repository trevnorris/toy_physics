## 1. Hypothesis H on this operator

### H-planar

On a one-direction background (R1: every profile jet with a 2- or 3-index zero) and perturbations independent of direction 3 (class P), the in-plane reflection \(x_3\to -x_3\) splits the linear theory into:

| sector | fields on P |
|---|---|
| **even** | \(u_1,u_2,\theta,e_W,\zeta_\pm,\delta p_s,\mu_s,\mathcal A_s,J_s,V_s,\varphi\) |
| **odd** | \(u_3\) only |

An \(x_3\)-independent scalar cannot be odd unless it is identically zero, so the odd-sector bulk field is empty. That is the representation of a polar vector: its odd part is its direction-3 component (`01` stdout: `R_on_polar_u = (u1, u2, -u3)`).

The S11c-b stored-energy family does not mix those sectors. The engine builds invariants by Kronecker contractions only (`delta_contractions` in `S11c_b_brane_operator_sympy_audit.py`; no `LeviCivita` in that file). Restricted to R1+P, that family has

- `uniform_mixed_count = 0`
- `new_mixed_count = 0`
- a live odd self-energy `(d1_u3**2 + d2_u3**2, d1_u3*g1*u3)`
- `|∇×u|²` mixed piece `0`

(`01_reflection_and_energy_parity.out`.) P1 holds for the accepted 40-term basis.

Face geometry, constraint, and both anchorings stay even:

- Graph \(h_s = s W(x_1)/2+\zeta(x_1,x_2)\) has \(\partial_3 h=0\), so \(n_3=0\).
- \(V_s=\hat n\cdot v_\text{face}\) has `coeff_u3t = 0`.
- Traction work \(\mathbf t\cdot\delta u_3=0\) because \(\mathbf t\parallel\hat n\).
- \(J_s=\Lambda_A\mathcal A+\Lambda_V V\) therefore sees \(u_3\) only if \(\mu_\theta\) does; \(\mu_\theta\) does not, by the Kronecker count above.
- Constraint divergence on P has no \(u_3\) (\(\partial_3 u_3=0\)).
- MATERIAL_ADVECTED linear carrier \(\mathbf u\cdot\nabla\rho\) is \(u_1\partial_1\rho\) only (`adv_coeff_u3 = 0`).

(`02_faces_constraint_anchoring.out`.) P2 and P4 (pin B, both anchorings) hold on this class. P3 remains what A says it is: the drain is absent from every derived operator (spec `:90–91`).

A’s closure reading is right for this bulk. S11b’s bulk is a scalar potential, \(\mathbf v=\nabla_4\varphi\), traction \(t_s=-(\delta p+\Lambda_X\mathcal A)\hat n\). With \(n_3=0\) the twist row has no bulk operand, and a scalar DtN cannot manufacture one: \(\nabla\varphi\) is irrotational, so it has no toroidal content (`04`: `scalar_bulk_toroidal_content = 0`). Part 1 still has to print those dependences; the symmetry argument is not a substitute for that emit.

### Rotation of oblique waves

A, §1: “That background is also invariant under rotations about direction 1. So each tangential Fourier component of an oblique perturbation can be rotated into this form.”

That rotation is the in-brane \(SO(2)\) in the \(x_2\)–\(x_3\) plane. \(W_\mathrm{bg}(x_1)\) is invariant under it. A numeric/symbolic map with \(\psi=-\mathrm{atan2}(k_3,k_2)\) sends \((k_2,k_3)\to(k_\perp,0)\) (`04`: `numeric_k2p = 5.0`, `numeric_k3p = 0.0`). The perpendicular polarization becomes \(e_3\). Without R1, \(W(x_1,x_2)\) breaks that \(SO(2)\), and the reduction fails. v2’s R1 is the condition that makes the claim true.

### H-round

Toroidal (magnetic) VSH parity \((-1)^{\ell+1}\), spheroidal and scalars \((-1)^\ell\). Rotation conserves \((\ell,m)\); inversion conserves parity. Same-\(\ell\) toroidal and scalar are opposite. Toroidal \(\ell\) shares parity with spheroidal \(\ell+1\), and \(SO(3)\) blocks that mixing. A’s bookkeeping is the standard one (`04`).

R-LEAK-1 protects one of the two in-plane polarizations (the twist). The divergence-free spheroidal polarization has scalar parity and is the round analogue of TM. A’s table already sends that piece to R-LEAK-2.

### Finding 1 — R1 / K1 / K2 index labels can miss the SymPy engine

**B §2:** “Use the engines’ three in-plane directions, called 1, 2 and 3 here.” Then: “Every background profile jet carrying any index 2 or 3 is zero.” Class P is independent of direction 3; K1’s \(\hat e\equiv(\sin\beta,0,\cos\beta)\) is in components (1,2,3); K2 is \(\varepsilon_{ijk} g_i\partial_j u_k\).

**Engine:**

```
DIRECTIONS = range(3)          # loop indices 0,1,2
u = tuple(... for a in range(1, 4))   # symbols u_1, u_2, u_3
spatialCoordinates = {xOne, xTwo, xThree}  # WL, 1-based
directions = Range[braneDimension]         # {1,2,3}
```

(`06_engine_index_and_form.out`.)

Zeroing Python loop indices 2 and 3 does not implement R1: there is no index 3, and index 2 is only the last direction. The `*_d2` jet (`u_*_d2`, engine direction 2 / B’s “2”) would stay live. Then the background is not one-directional, A’s rotation reduction is false, and K2 \(= a_{K2}\,g_1\theta\,\partial_2 u_3\) sits on whatever direction the builder actually kept.

Wolfram’s `{xOne,xTwo,xThree}` matches B’s 1,2,3. The hazard is the SymPy loop. B asks the builder to state the map; the restriction sentence still says “index 2 or 3” without binding that phrase to symbol names versus `DIRECTIONS`.
