## Verdict: Fork B, NARROWLY (Claude+Codex agreed)

A full Path-A run **can** change the realized closed-system `R_norm`, **but not by introducing new free
`G_U/G_W` magnitudes.** Reciprocity is exact at the action level: the return sources are adjoints/variations
of the *same* parent kernels already used in the forward chain, so closing the loop creates **no new numerator
knob**. `N0 = (P/Δ)²` with `P = Ω_U²G_W + R·G_U` is forward-determined (`compact.md:3946-4000`); decision-04 is
RIGHT that the basis-invariant forward `N0` needs no `S_η^(A)`.

The ONLY defensible mechanisms by which Path A can move `R_norm`:
1. **promoted wall dynamics** (`S_Σ[R]`) changing `K, M` → `D0`;
2. **a re-solved self-consistent background** changing the whole coefficient bundle `(K, B_n, Z_n, N0)`;
3. **a genuine near-pole / soft-wall denominator effect** (`D0 → 0`).

All three act through the **denominator `D0 = K − B0 − Z0`** or the **background**, never the numerator.

### Reciprocity (the structural basis)
- **Matter** return is EXACT: `L_ψ` has the single interaction term `−V_conf(X;Σ)ρ` (`compact.md:560-565`);
  with `δΣ = −η`, the forward source is `δV_conf = −(V_wall'(Σ0/ℓc)/ℓc)η` (`compact.md:1063-1084, 1424-1428`),
  and the return source is the SAME kernel against `δρ` (`stage001_geometry_lift.md:349-355`). ρ↔η variation
  of one action term ⇒ self-adjoint, no new magnitude.
- **Gauge** (`S_η^(A)`): the same variational logic applies in principle (the Maxwell source is generated by
  varying the covariant matter action, not an independent source — `compact.md:622-629, 655-658, 678-685`), so
  it too introduces **no new free magnitude** — BUT it is still "named, not formulated" (`decisions/02:24-28`):
  determined by the same action, **still needs derivation + audit**.

## The sharpening that reconciles Fork B with decision-02 ("R_norm is ω⁰-S_η-independent")

decision-02 correctly classified `R_norm` as independent of the **dynamical (ω≠0, WP3) return response**
`S_η^(ψ,A)`. That stands. Fork B does NOT contradict it, because **Path A enters `R_norm` through the
STATIONARY self-consistent BACKGROUND, not the dynamical return response:**

- The M1c effective-closure run **froze the throat shape `R0(w)` by hand** (the GATE-A cubic smoothstep,
  `decisions/07`). `B0, Z0` (the conservative matter/gauge back-reactions on the wall) are already in `D0`, but
  they were computed **on a hand-frozen geometry**.
- Promoting `S_Σ[R]` makes `R0(w)` a **derived self-consistent equilibrium** (the static wall balance: `S_Σ`
  stiffness against the static matter/gauge `S_η^(ψ,A)` force), NOT a free choice. The derived geometry gives a
  different `(K, B0, Z0, N0)` bundle → a different `D0` → a different `R_norm`.
- So the legitimate Path-A lever on `R_norm` is mechanism **#2 (self-consistent background)** — replacing the
  frozen-geometry free_choice with a forced equilibrium — plus #1/#3 acting through `D0`.

Currently `K=4.06`, `B0+Z0≈0.0047`, `D0=4.056`. To reach `D0≈2.5e-7` requires `K` to nearly-totally cancel
against `B0+Z0` — an **extreme (~1.6e7) near-pole**. This is **"not plausible without a target-blind
structural reason forcing `K ≈ B0+Z0`; otherwise it is forbidden fine-tuning."** Implications:
- Path A is the decisive `R_norm` re-test, but the **honest prior is that it will STILL MISS** unless the
  promoted self-consistent dynamics structurally drives the equilibrium to marginal stability.
- We **may NOT tune the posited `S_Σ` constitutive functions to force `D0 → 0`** — that is the same forbidden
