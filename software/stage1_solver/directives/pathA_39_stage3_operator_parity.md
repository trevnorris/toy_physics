### §2B. The finite canonical slot (Blocker 1)
A canonical `O(V¹)` operator slot is the tuple
`slot = (X, a, M, coeff_type, p_f)` with a canonical string ID `X|a|M|coeff_type|p_f`:
- `X ∈ {iV·k, ωV·k}` — external scalar factor (V·k trace only; both `P_w`-even). [Adjoint: `V·k` Hermitian ⇒ `iV·k`
  anti-Hermitian; `ωV·k` Hermitian.]
- `a ∈ {0,1}` — charge sign-spurion power `sᵃ` (`a=0` = `P_w`-even external / sign-even; `a=1` = `P_w`-odd external /
  sign-odd = charge-linear). Leading truncation: `O(V¹)`, `O(s¹)`.
- `M` — field-space matrix, from **symmetric {ηη, nn, ττ, ηn, ητ, nτ}** ∪ **antisymmetric {[ηn], [ητ], [nτ]}** (6+3=9).
  Each `M` carries `σ_Aσ_B` = product of the two component parities (ηη,nn,ττ,ηn ⇒ +1; ητ,nτ ⇒ −1) and an adjoint class
  (symmetric ⇒ self-adjoint bilinear; antisymmetric ⇒ anti-self-adjoint, contributes only paired with an odd-adjoint
  `w`-factor or `i`).
- `coeff_type ∈ {C, B, K}` — `C(w)` (`N_w=0`, potential; `w`-module self-adjoint), `B(w)` (`N_w=1`, advection; canonical
  `w`-module `A_B ≡ ½[B D_w + D_w B]` is **ANTI-self-adjoint** — the Hermitian phase is carried by the external factor
  `X`, NOT baked into the module; **Convention A**, Blocker 2), `K(w)` (`N_w=2`, `−D_w K D_w`; `w`-module self-adjoint).
- `p_f ∈ {even, odd}` — parity of the abstract coefficient function of `w` (the coefficient is a FREE even-or-odd function
  slot, characterized only by `p_f`; this is what makes the manifest finite — NOT an infinite function space).

Raw manifest = `2·2·9·3·2 = 216` slots. The gate emits the FULL manifest table (every ID with its `σ_Aσ_B`, `N_w`, adjoint
class, `p_f`) and the expected counts BEFORE verdicting; the deleted-operator control (§5) deletes one canonical ID after

failure). The `BASIS_INCOMPLETE` control operates on the raw (pre-quotient) count.

### §2C. The two filters, computed mechanically (never asserted)
1. **Hermiticity filter (Blocker 2, Convention A — one consistent convention throughout).** Keep only slots whose assembled
   real-quadratic-action term is Hermitian. Adjoint signs (both engines verify per representative; `+1`=self-adjoint,
   `−1`=anti-self-adjoint): `D_w†=−D_w` (slab BCs kill surface terms); **w-module** `C(w)`=`+1`, canonical advection
   `A_B≡½[BD_w+D_wB]`=`−1`, `−D_wKD_w`=`+1`; **field-matrix** symmetric `M`=`+1` bilinear, antisymmetric `M`=`−1` bilinear;
   **external** `iV·k`=`−1` (anti-Herm), `ωV·k`=`+1` (Herm). A slot is retained iff the PRODUCT of the three adjoint signs
   `{X, M, w-module}` = `+1` (Hermitian). Worked, now-consistent examples: `iV·k`(−1)×sym `M`(+1)×`A_B`(−1) = `+1` →
   **Hermitian, retained** (an advection/gyroscopic term); `ωV·k`(+1)×sym `M`(+1)×`A_B`(−1) = `−1` → anti-Herm, excluded;
   `iV·k`(−1)×sym `M`(+1)×`C`(+1) = `−1` → excluded; `ωV·k`(+1)×sym `M`(+1)×`C`(+1) = `+1` → **retained** (a Doppler
   potential term). Provide the full adjoint table as engine output.
2. **Parity filter + the law.** `π_P = (−1)ᵃ · σ_Aσ_B · p_f · (−1)^{N_w}`, computed BOTH via the rule AND via `P Ô P⁻¹`
   (must agree — dual-method integrity). The full spurionized term is `P_w`-invariant (physical) iff `π_P=+1`. Retain the
   `π_P=+1` Hermitian slots = the physical `O(V¹)` action.

**Consequence to be REPRODUCED, not assumed:** among retained slots, `a=0` ⇒ `σ_Aσ_B·p_f·(−1)^{N_w}=+1` ⇒ commutes with
`P_w` ⇒ preserves combined odd/even sectors (gravitomagnetic). `a=1` ⇒ `σ_Aσ_B·p_f·(−1)^{N_w}=−1` ⇒ anticommutes with

parity `p_f`, OR the `D_w` count `N_w` — NOT necessarily field-space off-diagonal; Blocker 5). These `a=1` slots are the

5. **Matrix-element witnesses (Blocker 3).** For each `a=1` slot emit the SYMBOLIC overlap functionals

   an ALLOWED parity-respecting WITNESS coefficient/profile (of the slot's `p_f`) that makes at least one overlap nonzero.
   **The verdict rests on: (allowed `a=1` slot exists) ⊕ (a parity-respecting witness gives nonzero `f₀→even` overlap).**
   Parity-class membership is NECESSARY not SUFFICIENT (a specific tensor can be accidentally orthogonal to a specific mode
   pair). The realized nonlinear-throat coefficient is NOT computed — this establishes ALLOWED-AND-UNPROTECTED with a
   generic nonzero witness, NOT computed-present magnitude. **At `ω=0` (the inherited pathA_38 static-mode basis, where
   `f₀`/`wall_partner`/`tau` live), the `ωV·k` slots carry NO witness burden — the verdict rests on the `iV·k` slots; the

6. **Decide** (§4).
