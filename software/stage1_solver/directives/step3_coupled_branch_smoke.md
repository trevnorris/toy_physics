  **engineering-smoke validation report only**.

are **OUT of this step** — they come later, after the value-freeze and guard gates.

## 2. Scope

### IN — mandatory

**A. The coupled stationary isotropic residual on the `(r,w)` mesh** (prereg §B: stationary drops
`t`, isotropic drops `Ω`; fields are functions of `(r,w)` with the full `r²` measure). Assemble a
single residual `F(U)=0` over the coupled field set (the Madelung/axisymmetric working set, prereg
§C: `ψ_real, ψ_imag` (or amplitude/phase), `A_0, A_r, A_w`, the throat geometry `R_0(w)`, and a
gauge multiplier — ≈5–7 fields/cell). The residual must **couple** the certified sectors
self-consistently:
  - **Matter — quintic gauged-GNLS, stationary** (compact §2.5.1, §2.4.1): `iℏ D_t ψ →` stationary
    eigenproblem `[-ℏ²/2m D_iD_i + V_conf + h(ρ)]ψ = μψ`, with the **covariant derivative**
    `D_iψ = ∂_iψ − (i q_⋆/ℏ) A_iψ` (so the gauge field `A` enters the matter operator) and the
    production enthalpy `h(ρ)=(5K/4)ρ⁴`, `ρ=|ψ|²`.
  - **Maxwell — localized, gauge H=Z, sourced by the matter current** (compact §2.5.3, §2.4.2):
    `∂_M(Z(w)F^{MN}) + (1/ξ)∂^N(Z ∂·A) = μ₀ J_ψ^N`, where `J_ψ` is the **dynamical matter current**
    `j^i=(ℏ/m)Im(ψ* D_iψ)` generated by the matter fields (compact §2.5.2). Honour the bookkeeping
    rule (compact §2.4.2): the matter current is generated by the covariant matter action and must
    **not** be double-counted as an explicit Maxwell source. H=Z is frozen (prereg §D).
  - **Throat geometry `R_0(w)`** with the open-finite-throat BCs (prereg §D, `NONLINEAR_PROTOCOL_V2`
    L35–38): **Dirichlet mouth** (`R(0)=R_mouth>0` fixed positive), **open-impedance / Robin exit**
    (`R(L)=R_exit>0`, finite — no hard cap), `r=0` regularity (zero inner-face area), mixed channels
    `A_w` alive. For this isotropic smoke `R_0(w)` may be a **prescribed placeholder profile** if the
    sources do not pin a static balance for it — state and label the choice.
  - **Wall sector:** because WP1 is *isotropic*, the angular deformation `η=0`, so the wall
    `S_eta^(2)` operator is primarily a **WP3 (step-8) concern**. Include the wall↔branch coupling
    **only as far as the canonical sources pin it for the isotropic branch**; where the coupling is
    underspecified, **STOP and flag it precisely (file:line + the specific gap) rather than invent
    it** — and proceed with the matter+Maxwell coupled system, which is the mandatory floor. The
    wall operator itself is already certified (step 2); do not re-certify it here.

**B. Continuation-in-K** (plan §6, predeclared): a config-declared schedule that starts from a
**milder EOS** and continues to the **stiff placeholder target K**, re-solving Newton at each step
using the previous solution as the initial guess. The schedule (start K, target K, step count/law)
is declared in config **before** running.

**C. Newton–Krylov convergence** (reuse `newton.py`): solve `F(U)=0` at coarse resolution with the
JFNK machinery (GMRES on JVP, Armijo). All controls explicit in config. The change-of-variables
escape hatch (`log ρ` / regularized density) from plan §6 may be used **only if** near-vacuum
positivity is the observed failure — do not reflexively switch if `ψ_real,ψ_imag` is smoother; if
you use it, justify from the observed residual behaviour.

**D. §J.1 correctness gate — manufactured-solution test on the FULL coupled residual.** Extend the
step-2 MMS approach to the *assembled coupled* system: pick smooth analytic fields for all coupled
unknowns, derive the exact coupled forcing **symbolically (sympy) from the continuum coupled
operator** (NOT from the discrete code), and certify the discrete coupled residual converges to it
at formal order under refinement. This MUST exercise the **cross-sector coupling terms** (the `A_i`
inside the matter covariant derivative; the `J_ψ` source in Maxwell) — not just the per-operator
pieces already certified in step 2. This is the load-bearing proof that the coupling is assembled
correctly.

**E. "Fails-loud" diagnostics** (plan §6, §165): report the **Newton residual history**, the
**GMRES iteration count per Newton step**, and how both behave **under coarse-grid refinement** (do
GMRES counts stay roughly grid-independent, or grow — the signal that the deferred PETSc/multigrid
D2 stack will be needed at production scale). A stall (residual stops dropping) or GMRES blow-up is
a **finding to diagnose** (continuation/preconditioner/variable-change), never to hide.

**F. Resolution ladder.** Run a coarse-grid ladder (e.g. up to ~`512×256 ≈ 0.8M` DOF, plan §64–66)
**as far as this laptop allows**; report per level: DOF, wall-clock, peak memory, Newton iters to
converge, final residual, GMRES counts. State where the laptop limit is hit.

### OUT — do not touch this step

The field→coefficient extraction map / any `D0,P0,…` packet (prereg §F); any §H target or
comparison; the export guard scripts and `simulation/output/`; freezing the real `free_choice`

**R5 — NON-FROZEN smoke discipline (keep the guard firewall intact).** All output and manifests are

blind**. Do **not** write under `research/pde_audit/simulation/output/`; do **not** import,

   open-throat BCs (Dirichlet mouth, Robin/open exit, `r=0` regularity) — reusing steps 1–2.
2. **Coupled MMS (§J.1):** the full coupled residual converges to a sympy-derived continuum forcing
   at formal order, exercising the cross-sector coupling terms; non-circular (forcing from the
   continuum operator, never the discrete code).
3. **Newton + continuation-in-K converges** on a coarse mesh to the configured residual tolerance;
   residual history + per-step GMRES counts reported.
4. Jacobian JVP cross-check on the coupled residual passes within a stated tolerance.
5. **Resolution ladder** run as far as the laptop allows; per-level DOF / wall-clock / memory /
   Newton iters / residual / GMRES counts reported, including whether GMRES counts grow under
   refinement (the D2/preconditioner signal).
6. Determinism + manifest, **clearly labelled non-frozen engineering smoke** (placeholder params,
   no physical packet, target-blind); guard scripts untouched; nothing written under
   `simulation/output/`.
7. A concise **engineering-smoke validation report** (markdown/YAML, KB-scale) stating: the coupled
   residual form + the source lines it transliterates, the placeholder parameters used (labelled),
   the coupled-MMS convergence table, the Newton/continuation convergence + diagnostics, the
