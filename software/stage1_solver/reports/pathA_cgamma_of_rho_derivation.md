# Path-A `c_gamma(rho0)` Derivation

Date: 2026-06-22

## Verdict

**Type 4: DECOUPLED.**

For the canonical Path-A parent action, the physical photon cone is the cone of the independent localized Maxwell metric. With units restored,

```text
c_gamma(rho0) = c_* = beta_bulk_to_brane
d ln c_gamma / d ln rho0 = 0
```

where `c_*` is the absolute speed assigned to the flat Maxwell bulk-metric unit cone. The action does not derive `c_*` from `{K, m_GNLS, rho0}`.

The GNLS sound speed is instead

```text
c_s^2(rho0) = (1/m_GNLS) dP/drho = 5 K rho0^4 / m_GNLS
c_s(rho0) = sqrt(5K/m_GNLS) rho0^2
```

so

```text
lambda_gamma(rho0)
  = c_gamma / c_s
  = c_* sqrt(m_GNLS/(5 K rho0^4))
  = c_* sqrt(m_GNLS)/(sqrt(5K) rho0^2).
```

Thus, under a density change with the EM metric held fixed, `lambda_gamma proportional rho0^-2`. In a chosen uniform-density bulk, `lambda_gamma` is one physical speed-ratio input. The canonical action does **not** impose `lambda_gamma = 1`.

## Source Facts

The canonical parent theory declares a flat bulk metric,

```text
eta_MN = diag(-1,+1,+1,+1,+1),    Box_5 = -partial_t^2 + nabla_3^2 + partial_w^2.
```

This is the metric used by the localized gauge field (`research/pde/paper/pde.tex:242-248`). The exact parent action is a combined GNLS matter plus localized Maxwell system (`research/pde/paper/pde.tex:316-321`), but the matter speed and the Maxwell cone enter through different terms.

The matter sector is the gauged GNLS Lagrangian with covariant derivatives (`research/pde/paper/pde.tex:326-340`) and the frozen stiff EoS

```text
P(rho)=K rho^5,    c_s^2=(1/m)dP/drho=5K rho^4/m
```

(`research/pde/paper/pde.tex:342-352`). This is the only source of the `rho0^2` sound-speed scaling.

The Maxwell sector is

```text
L_EM = - Z(w) F_MN F^MN/(4 mu0)
       - (partial.A)^2/(2 xi mu0)
       - A_M J_ext^M
```

and variation gives

```text
partial_M[Z(w) F^{MN}] + xi^-1 partial^N(partial.A) = mu0 J_tot^N
```

(`research/pde/paper/pde.tex:357-416`). The density `rho` is not present in the Maxwell kinetic coefficient. The matter coupling supplies the source/current side; it does not replace the Maxwell kinetic metric.

The controlled far-field zero-mode reduction assumes `A_w approximately 0`, `partial_w A_mu approximately 0`, `J^w approximately 0`, and `F_mu w approximately 0`, giving

```text
partial_mu F_brane^{mu nu} = mu0_eff J_eff^nu,
mu0_eff = mu0/Z_int,
q_eff = q_*/sqrt(Z_int)
```

(`research/pde/paper/pde.tex:541-563`; charge normalization also at `research/pde/paper/pde.tex:289-295`). The Maxwell-only paper derives the same effective coupling and canonical charge normalization (`research/4d_em_fields/paper/4d_em_fields.tex:768-779`, `research/4d_em_fields/paper/4d_em_fields.tex:822-856`).

## Restored-Unit Maxwell Cone

The canonical papers often use a unit brane light-cone speed; the Maxwell paper states that factors of `c` can be restored by `t -> c t` and `partial_t -> c^-1 partial_t` (`research/4d_em_fields/paper/4d_em_fields.tex:269-285`). Let this restored absolute Maxwell cone speed be `c_*`.

After the zero-mode reduction, the source-free brane action for a transverse photon mode has the schematic kinetic density

```text
L_EM^0
  = (Z_int/(2 mu0 c_*^2)) E^2
    - (Z_int/(2 mu0)) B^2.
```

Equivalently,

```text
epsilon_eff = Z_int/(mu0 c_*^2),
1/mu_eff   = Z_int/mu0,
mu_eff     = mu0/Z_int.
```

Therefore

```text
c_gamma^2 = 1/(epsilon_eff mu_eff) = c_*^2.
```

The localization normalization `Z_int` and the Maxwell coupling `mu0` cancel from the cone. They control coupling strength, not photon speed. This is exactly the distinction Gate 2 recorded: in bulk units `C_E=Z_int/mu0`, `C_B=Z_int/mu0`, so `C_B/C_E=1`, while the absolute speed map remains `beta_bulk_to_brane` (`software/stage1_solver/reports/pathA_22b_minimal_combination_xi.md:118-135`). With units restored, the same statement is `C_B/C_E=c_*^2`.

For a transverse plane wave `A_T ~ exp[-i omega t + i k x]`, the principal operator is

```text
P_T = (Z_int/mu0) (omega^2/c_*^2 - k^2),
```

so

```text
omega^2 = c_*^2 k^2,
v_phase = omega/k = c_*,
v_group = d omega/dk = c_*.
```

There is no `rho0`, `K`, `m_GNLS`, or `q_*` in this characteristic speed.

## Medium Coupling Check

The only canonical way the homogeneous condensate enters the Maxwell equation is through the matter current. The parent source bookkeeping says the dynamical matter current is generated by minimal coupling and must not be double-counted as an explicit Maxwell source (`research/pde/paper/pde.tex:370-374`). In the linearized PDE, the current variation contains

```text
delta J^0 = q_* delta rho,
delta J^i = q_* delta j^i,
delta j^i includes -(q_*/m_GNLS) rho0 delta A^i + ...
```

(`research/pde/paper/pde.tex:903-931`). On a homogeneous neutralized background this can generate a London/plasma lower-order term for transverse gauge perturbations. Keeping that term schematically gives

```text
(Z_int/mu0) (omega^2/c_*^2 - k^2) - q_*^2 rho0/m_GNLS = 0
```

or

```text
omega^2 = c_*^2 ( k^2 + mu0 q_*^2 rho0/(m_GNLS Z_int) ).
```

This term is density-dependent, but it is a mass/plasma gap, not a change in the principal cone. Its finite-`k` phase and group velocities are

```text
v_phase = c_* sqrt(1 + omega_L^2/(c_*^2 k^2)),
v_group = c_* / sqrt(1 + omega_L^2/(c_*^2 k^2)),
omega_L^2 = c_*^2 mu0 q_*^2 rho0/(m_GNLS Z_int),
```

so the wavefront/high-frequency speed remains `c_*`. This does not produce `c_gamma = c_s`, and it does not give the `rho0^2` scaling required for a medium-locked light cone. It is a separate low-frequency/gapped-response effect.

## Constitutive Lock Test

To get a medium-locked photon from the canonical Maxwell form, one would need the restored constitutive product to satisfy

```text
epsilon_eff(rho0) mu_eff(rho0) = 1/c_s^2(rho0)
                               = m_GNLS/(5 K rho0^4).
```

Equivalently, since the reduced canonical action gives `mu_eff=mu0/Z_int`, exact equality would require

```text
epsilon_eff(rho0)
  = (Z_int/mu0) m_GNLS/(5 K rho0^4),
```

or, in metric language,

```text
c_*^2 = 5 K rho0^4/m_GNLS.
```

The canonical action imposes neither condition. It has a common scalar Maxwell normalization `Z(w)/mu0`, not separate electric and magnetic constitutive functions with a density-dependent ratio. Even if a future branch model made `Z_int` depend on the background state, the common `Z_int` factor would still cancel from `C_B/C_E` unless the action were changed to weight electric and magnetic terms differently or to use the acoustic metric in the Maxwell kinetic term.

Therefore:

```text
Type 1 MEDIUM-LOCKED: false for the canonical action.
Type 2 SAME-SCALING-DIFFERENT-COEFFICIENT: false for the canonical cone.
Type 3 DIFFERENT-SCALING: false for the canonical cone; only a lower-order plasma gap can carry rho0.
Type 4 DECOUPLED: true.
```

The minimal added coupling that would lock photons to sound is an explicit constitutive or metric postulate, for example

```text
L_EM -> -sqrt(-g_ac) Z(w)/(4 mu0) g_ac^{MP} g_ac^{NQ} F_MN F_PQ
```

with `g_ac` the GNLS acoustic metric, or an equivalent brane constitutive law with `epsilon_eff(rho) mu_eff(rho)=m_GNLS/(5K rho^4)`. That is an added modeling postulate, not a consequence of the canonical fundamental-gauge action.

## Legacy Emergent-Photon Contrast

The superseded `research/em_fields` construction is a genuine example of medium locking. It builds an acoustic metric for perturbations and states that in the weak-flow limit the effective light speed is `c = c_s` (`research/em_fields/paper/em_fields.tex:146-172`). It also assembles the effective EM four-potential with `c` identified with the sound speed in that acoustic metric (`research/em_fields/paper/em_fields.tex:472-482`).

That is not the canonical Path-A construction. The canonical action replaced the acoustic-photon reuse with a fundamental localized Maxwell field on the flat bulk metric. The legacy result shows what a lock would look like; it does not derive a lock for the canonical action.
